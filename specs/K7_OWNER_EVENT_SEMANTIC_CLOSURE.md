# K7 owner-event semantic closure

Contract `2.0.23` closes the 71 owner-emittable V6 counter paths as
nonformal materialization candidates.  It does not create a counter record or
vector.

The authority consumes the exact production role manifest, joined broker
runtime and publicly replayed child-business bytes.  It reconstructs and
verifies every node of the five-stage partial-native chain, binds the chain to
the production business-result ID, digest and source archive, and checks all
89 registered owner sites against the loaded source bytes.

The frozen source inventory contains 59 accounting-hook calls with 54 unique
module/symbol/dispatch keys.  A site may contribute only exact unit SUM events
whose stage, path and site identities match the V3 boundary manifest.  A
zero-valued candidate is issued only after the corresponding stage and every
source site for that path have closed; missing or aborted evidence is never
interpreted as zero.

The result contains exactly 89 site closures and 71 path candidates, preserving
positive event order and explicit complete-window zeros.  Mutation,
reordering, path/stage transplant, source/archive divergence, incomplete
stages and hook-inventory changes fail replay.

The process-local post-exec attestation is not serialized.  This slice records
the narrower exact bootstrap control-flow and two directly reaped zero exits;
it does not relabel that derivation as an exported post-exec attestation.
The nine shared paths, 114 profile-zero paths and eight derived paths must join
under one occurrence before formal materialization.
