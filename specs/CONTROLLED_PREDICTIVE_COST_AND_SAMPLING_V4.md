# V4：精确经验商对照、局部更新和风险采样诊断

本开发协议在本轮比较与采样曲线执行前于 2026-09-08 写入。V3 的结果保持原样，其 13 个实例全部视为已暴露开发数据。

## 要回答的问题

1. 查询引导细化相对同样本、零容差的精确经验商，是否提供值得支付构建成本的额外压缩或计划质量？
2. 保持 V3 的细化判据和拆分规则，局部更新能否减少重复工作？
3. V3 留下的真实风险决策错误来自哪些经验概率与后续价值偏差？增加匹配样本后还剩多少错误？

本轮直接实现并比较以上对象。简单精确经验商若在已测范围中更合适，后续有限模型工作以它为默认基线，不为了维持复杂方法而扩大成功措辞。

## 比较 A：同信息量与细化成本

每个模型读取同一份 `sample_model` 经验核，64 次／动作行，种子 `832101,832102,832103`。四组分别为完整状态经验模型、`build_quotient(empirical)` 的零容差精确经验商、原 V3 全量重检细化、V4 局部更新细化。精确环境仅作最优参考和冻结策略审计。这里的“精确经验商”是对经验核精确聚合，不是取得了真实精确概率。

沿用 V3 六个构建查询与四个探测查询，模型每次构建后复用十个查询。V4 保持原初始容差 `reward=0.01, TV=0.2`、数值误差 `1e-10`、成员策略改进及收益／失败／成功预测判据，以及按当前动作响应签名同时拆分的规则。

V4 使用稳定 cell ID 和缓存。拆分后重新编译拆分子 cells 及其直接前驱的动作行；只更新拆分处和传递前驱范围内的规划、成员策略后果与残差。平均 cell 动力学改变会影响其所有成员，因此失效范围按编译模型的转移并集向前驱传播。维护依赖关系、缓存与最终几何统计均计入实际构建成本。

数据固定如下，全部保留，不按冲突或候选表现筛选：

| 数据 | 来源数量 | Horizon |
| --- | ---: | ---: |
| V3 原有全部实例，标记已暴露 | 13 | 原设置：一个 H2、十二个 H3 |
| 本轮新开发实例 | 12 | 3 |

新实例使用原 V2 `_source_board` 的三个 family：`cross_axis_pairs,gradient_bottleneck,near_goal_corridor`。各 family 使用基准种子 `836101,836201,836301,836401` 加从零开始的 family 序号，不做旋转或替换。完整闭包上限 30,000 状态，超预算保留。

报告根部与全部活跃状态的完整策略目标损失、收益／风险预测误差、严格查询切换、cells／动作行／存储、实际构建和查询工作。V4 对 V3 另外比较按成员集合对齐的分区、动作期望收益和后继 cell 概率；浮点误差和动作并列单独解释，不能把优化引起的行为变化掩盖为速度提升。

各模型运行次序随实例／种子轮换，减少固定顺序的计时偏差。计时只覆盖本次实际运行，不作显著性或回本外推。成本列出构建、十查询规划、预测评估、精确审计以及公共闭包和采样。源码优化造成的真实工作量减少用计数核对，三个采样重复不充当相同模型的计时重复。

## 比较 B：暴露错误的分解与匹配采样曲线

首先仅对 V3 已暴露的 `cross_axis_pairs_835401` 与 `gradient_bottleneck_835402` 重建原始 64 次／行的全局随机流，以核对错误根查询并分解：最优动作价值差距、根动作经验概率误差、后续冻结策略损失和后续价值预测偏差。记录对应动作的漏见支持质量与终态概率偏差。精确环境可以解释这些已暴露错误，不参与下一阶段采样分配或模型拟合。

样本量曲线使用上述两个已暴露来源，加四个新开发来源：`cross_axis_pairs_837101, cross_axis_pairs_837201, gradient_bottleneck_837102, gradient_bottleneck_837202`。所有实例 H3，完整闭包上限 30,000；仍保留全部结果与预算失败。

每个动作行建立确定的独立随机流，三个种子仍为 `832101,832102,832103`。依次采样 64、再增加 192、再增加 768 次，得到每行累计 `64,256,1024` 的嵌套前缀；各阶段累计采样耗时与真实新增／累计样本数均记录。这个新逐行随机流的 64 前缀和原 V3 全局随机流分开报告。

每个经验核同时提供给完整状态模型和零容差精确经验商，复用同样十个查询，逐状态审计已冻结策略。报告绝对错误、查询切换以及候选相对同样本基线的额外损失。增加样本不是默认成功条件，残留错误与非单调变化均保留。未使用真实最优动作指导抽样，也未将真实 2048 的 spawn 概率作为拟合参数。

## 验证与交付

局部更新的针对性测试检验未受影响分支被复用、拆分经前驱传播、并与 V3 的分区和计划后果一致。采样测试检验嵌套计数、相同数据供给两组以及误差分解的恒等关系。比较程序检验精确经验商没有读取真实概率、全状态检查及固定实例分母。

分别保存紧凑的比较结果和采样诊断，保留按实例／种子的指标、工作计数和必要反例，不重复写入完整状态闭包或每轮所有成员。两个开发实验各执行一次；代码错误若导致中止则如实记录原因，不能用重跑隐藏科学负结果。

## 范围

V4 是有限模型构建与风险采样开发，仍使用逐实例状态查表，未训练可迁移编码器。样本量曲线中新来源仅四个，不承诺其中必有严格冲突；源实例、采样种子和状态不能混为独立样本。经验一致性不是真实概率的置信保证。旧 V3、U005 科学 FAIL、U006 未启动状态及 V2 保留的 24 个候选均保持原样；本轮仅在本地生成数据。
