# V300：固定纯 B 数据的 H2 控制目标对照

V298 的 MC 更新使整局收益下降；V299 已排除单局归一化更新过冲，
但没有建立控制目标不一致的因果解释。本轮只干预学习目标。

固定 V298 全64条 B 历史、四个原始 SOURCE 父模型、完整游戏的
时间顺序80/20划分、32重数 N-tuple 单表、alpha=0.0025，以及
逐游戏地址总出现次数归一化。MC 与 EXPECTED_CONTROL 从原 SOURCE
各自初始化，拟合同样的非胜利 afterstate；每局目标与残差全部在
该局写表前计算，随后一次提交。没有 V291 的 A 阶段更新。

三臂 SOURCE、MC、EXPECTED_CONTROL。MC 使用原 V290 后缀目标，
要求原 V298 拟合计数、首尾样本和完整留出预测精确复现。
EXPECTED_CONTROL 对 afterstate 的空格均匀枚举 rank 1/2，计算
下一步合法动作的最大 reward/2048 + 当前叶值，再取模型期望。
胜利与无合法动作分别采用原 +4/−4 终端约定，当前动作奖励不重复计入。
该期望就是现有 H2 根动作的未来项。整个离线拟合与评价共用
V298 FIT 前缀观测得到的固定 spawn 概率；不使用真实0.5或留出观测。

三臂用新配对整局流评价：每 life 每臂32局，seed=
300900000000 + life*1000000 + episode，真实 B 概率0.5，H2 depth=2，
max_steps=8192。评价中不更新叶值、记忆或训练流。保留全部
WON/LOST/CUTOFF，禁止挑历史或重跑种子。

主终点 EXPECTED_CONTROL−SOURCE 的整局 utility，先游戏再 life 等权。
四个固定父源组内各抽16条完整 life，20,000次配对 bootstrap，
seed=30000001。95%区间下界严格大于0且全臂无 CUTOFF 才支持收益。
EXPECTED_CONTROL−MC、MC−SOURCE 及完整留出事实回报 MSE/MAE/bias
均为次指标，不能替代主终点。固定训练历史使本轮仍是开发性目标对照；
新的评价流不构成新的独立训练队列。

本轮不新增训练环境采样。三臂经济输入都包含原 SOURCE、动力学和
全部原 B 获取成本19,698,507 raw；物理输入只支付一次。
另列实际重构、初始化、拟合地址写入、控制目标规划、留出评分、
新整局评价、编译与 CPU 成本。同样本与同更新次数不表示同计算预算。

若主终点不支持收益，结束当前目标支线，下一阶段转向实质不同的
风险/奖励表示；不调整 alpha、预算、种子或终点追求本轮阳性。
若支持收益，下一步才冻结该目标并在全新训练队列确认。
