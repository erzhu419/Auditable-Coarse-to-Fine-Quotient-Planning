# V8：训练经验预测约束与机制族留出比较

本协议在 V8 真实开发实例拟合和候选结果产生前固定。V7 已证明可执行文件能运行，但训练状态的合并会丢失已有特征中的动作条件差异。本轮研究完整经验预测约束能否改善这一问题，并区分树容量、分割规则和运行实现的作用。

## 固定数据与四个场景

复用 V7 名册中的全部 16 个已暴露实例、原始棋盘、horizon、256 次／合法动作行、种子 `832101,832102,832103`、原六查询加四探测查询。闭包上限仍为 30,000 状态，完整枚举全部合法动作与生成结果；超预算和不满足训练约束的实例都保留，不截断或替换。

执行前另存 [V8 名册](../reports/controlled_predictive_cohort_roster_v8.json)，包含所有源和目标名称及固定角色：

- `PRIMARY_V7_SPLIT`：原来的三个变体 0 用于训练；保留全部 16 个实例的 V7 分组。此场景与 V7 作已暴露回归比较。
- 三个 `LOFO` 场景：每次完整留出一个 V6 机制族的四个变体，只以另外两个机制族的变体 0 训练。评估该目标族四例和两个训练来源，共六例。目标标为 `FAMILY_HELD_OUT`。

合计每个种子 34 个场景／实例项、三个种子 102 项。三个机制族留出场景的目标合计 12 个不同根，各自只作为一个折的目标；它们与主场景复用同一组开发材料，因此两者分别统计。训练来源在不同折重复，不作为独立样本。

每个原始实例／种子只创建一个经验核，全部场景和方法复用这个固定观测库。闭包也只构建一次。拟合函数只接收该场景声明的训练经验核和训练棋盘；经验库存在其他实例不表示学习器可以读取它们。名册与闭包重叠检查在任何拟合前完成。精确最优动作和查询都不进入拟合。

所有材料此前已被精确科学观察。本轮的留出只描述编码器拟合使用范围，不声明独立确认或此前未见的机制发现。V2 原 24 个延期最终候选不进入本轮。

## 不可合并的对象

保留 V7 的 31 个固定特征、剩余 horizon、终态优先级和合法动作分组。对于训练状态 s 与每个合法动作 a，构造经验平均奖励和观测后继经过已固定低层规则后的符号概率分布：

`signature(s) = ((a, mean_reward(s,a), distribution(code(next)|s,a)), ...)`。

同一分组内，签名不同的训练记录构成不可合并对。奖励与后继分布均使用完整经验值，不按风险阈值或查询权重选取坐标，不做舍入合并。在固定 256 次采样和本域归一化奖励下，这些观测均为可精确表示的二进有理数。此处的“精确”指当前经验核，仍有采样误差。

单独保护动作风险排序不充分：相同方向而不同幅度可改变权衡，且即时终态概率可能相同而后继的长期风险不同。完整签名使底层区分能进入上层目标。

## 固定约束学习器与容量对照

V8 约束树在每个强制分组内用轴向特征阈值递归分割。每一步选择能分开最多不可合并训练对的阈值；并列按固定特征序和阈值序选择。纯签名叶停止，否则继续分割。最小子叶为 1，不设任意深度上限；树受有限不同特征向量数量约束。

如果剩余记录的全部特征完全相同、经验签名仍不同，则保存一个未解决叶，并报告记录、特征、签名冲突和动作差异。运行规则不会插入棋盘字典或状态 ID 特判。相同纯签名的不同叶共用一个输出编码；不同混合叶各自保留编码。

规则按 horizon 自底向上完成，每一层用最终低层编码重新构造目标。低层有未解决冲突时，上层的局部纯签名不能解释为递归语义保持。只有全部训练分组约束满足，才标记训练递归约束完成；否则仍执行原定比较，报告实际损失。

另设容量对照：相同特征、来源、目标和纯签名编码复用，使用原 V7 的贪心多输出 SSE 分割，但最小子叶改为 1，深度上限取该分组记录数，使容量上限不约束可分割数据。SSE 仍要求大于 `1e-12` 的增益。这能区分原 V7 容量限制与约束优先分割（包括零 SSE 增益的必要分割）的作用；结果仍需结合实际剩余冲突解释。

本轮没有超参数扫描、验证集模型选择或按结果选择特征。

## 六组同样本比较

1. 完整状态经验模型。
2. 零容差精确经验商。
3. 原 V7 深度 4／最小叶 2 学习器，采用本轮公共运行实现。
4. 放开容量的 SSE 学习器，采用公共运行实现。
5. V8 经验预测约束学习器，采用公共运行实现。
6. V8 的动作后果打乱控制：相同冻结编码，逐状态循环移置合法动作的整条观测行；不重新拟合。

全部编码方法共用终态优化实现：保留 ACTIVE 的 31 特征和规则执行语义，对终态跳过无用的完整特征计算，构建时复用动作索引。该项先用语义等价测试核对。方法间质量差异来自各自学习规则；计算优化的工作量节省与 V7 旧计数单列，旧运行墙钟时间不构成同期性能对照。

每个场景／种子为三个学习器各拟合一次。每个实例六组各构建一次并完成十查询策略冻结，然后才生成精确最优参考与真实策略审计。报告根首步、根完整策略、全部活跃状态、查询切换、预测误差、同 cell 最优动作冲突，以及相对同样本完整状态的编码新增损失；最坏绝对损失和最坏新增损失分别记录。 对拟合诊断中保留的同特征碰撞状态，另从现成精确审计中记录各查询的最优动作集合，以区分经验频数差异与真实决策冲突；这些标签不回流拟合。

## 成本与交付

经验库的实际抽样只计一次；场景复用另报逻辑读取量，不当作额外独立观测。每个学习器每个场景／种子只计一次拟合，打乱控制复用 V8 拟合。场景成本给出 1／6／10 查询工作量，拟合分摊到声明场景的 16 或 6 个实例；另报一个目标独立承担全部源闭包、源观测与拟合时的成本。训练实例自己的源观测已含在当前成本中，不重复加计。

记录原始棋盘编码、目标构造、规则分割、聚合、DP、预测、真实审计、精确参考和库存序列化的时间及工作计数。每个场景独立比较，跨场景总工作量只按实际执行次数计费。

固定保存主场景、`v6_spawn_edge_rescue_2`、种子 832101 的 V8 编码器与模型；沿用已可执行的 V7 规则文件格式。运行交付包含树、有限转移、编码到 cell 对照与一个例子根，不包含完整棋盘／ground 状态映射。另在一个新进程查询收益 1、风险 0.3、目标 0.2，并与进程内同一冻结模型一致性比较。这只检查重载与执行，不检查该额外查询的真实最优性。

## 执行范围与判断

针对性测试用于检出：训练签名未完整保留；约束不能通过零 SSE 增益分割解决；相同特征冲突被隐藏；低层冲突被误称为递归通过；评估数据或精确标签流入训练；经验库重复采样计费；终态优化改变规则语义；场景源族与目标族交叉；策略未冻结就读取精确最优参考。实现错误先修复，再运行一次冻结科学比较。

本轮保留原 V7 失败和全部新结果。若约束在训练上仍不成立，区分特征混叠与分割问题；若训练通过但机制族留出失败，则结论限于训练经验模型；若容量对照同样改善，不把全部收益归于约束优先分割。没有预注册新的正式 Gate，也不按本轮结果改变阈值。

U005 科学 FAIL、U006 未运行及 V2 延期集合状态保持。完成一次本轮比较与一次重载后记录判断，不在同一协议内追加调参运行。
