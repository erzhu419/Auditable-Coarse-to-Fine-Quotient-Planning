# V62：13／15节点新图上的固定轨迹规模试验

冻结日期2026-09-12。四组各16图：13节点稀疏620000..620015、13节点密集620100..620115、15节点稀疏620200..620215、15节点密集620300..620315。稀疏／密集期望度数固定1.5／4.5，p=期望度数/(N−1)；使用原generate_graph(N, seed=graph_id, p)生成有向无自环ER图，只生成一次并留存边。

沿用V59解析单日／两步策略和V61轨迹执行器，K=2、T=3，每图每方法128回合，共16384条。每天真实余日分配、逐决策冷规划、严格最大值／字典序规则保持。随机流仍为Random(61000000+graph_id*1000+replicate)，replicate=0..127；先决策，再按排序边生成当天全部uniform，方法间共享日期×边对应关系，全部抽取和有效传播尝试分账。按图排序，偶数索引单日先、奇数两步先。

每图×方法累计2000000次动作估值、100000次决策、60秒墙钟软限保持。完整决策先收费留存，再按上述顺序检查>=，触限后不传播，留下收益为空的末条前缀并停止该块，其他块继续。准备GC、块后清理、规划、传播、留存及分析费用分列，所有失败和超限费用保留。不补图、不追加采样或预算。

新图没有旧动作证书。独立分析只核对实际访问的不同查询(graph,method,state,b,h)，每个查询重算一次短窗Q与搜索工作，重复访问复用新证书。核对器用入边失败概率乘积和独立目标结果枚举，末层用解析期望；不调用生产规划器，不构建完整策略树。Q误差容差1e−10，动作必须符合报告Q自身的严格最大值／字典序规则，不强求独立浮点求和的平手动作相同。全部独立查询、枚举和乘积费用记录，再复用V61独立随机传播重放核对每条轨迹及其工作。

主比较为四组各自的两步−单日收益：先在同图同replicate内配对，再算每图128个差的均值，最后对16图等权平均。主标准误为16个图均值的样本标准差/sqrt(16)，同时纳入图间和Monte Carlo变异；报告df=15的普通95% t区间，以及预定四项Bonferroni同时区间，临界值t.ppf(1−0.05/(2*4),15)。另列固定面板的Monte Carlo标准误sqrt(sum(图内差值方差/128)/16²)和普通95%正态区间，作为V61口径参照。主区间仍是有限图数的近似推断，不另设采纳Gate。

任一图×方法未完整时，该组主收益及完整回合成本比较为空；保留全部截断费用与缺失回合数，其他完整组照常报告。完整组记录逐回合规划动作估值、内部枚举、传播抽取、GC和总耗时。V61的9／11节点成本只作历史描述，不混入新图推断或宣称配对加速。无新RL、MCTS、完整策略评价或精确根价值校准；V61及更早费用全部保留。U005 FAIL、U006未启动及已关闭候选保持。
