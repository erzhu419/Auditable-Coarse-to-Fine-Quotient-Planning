# V240冻结：九例未获证查询的坏核可行性

固定V239原24例中的9个query_ready=false末期case，保持原顺序、已付费tapes、策略、费用、阈值960与regret=.05。本轮每例仅诊断一个原未获证risk比较：优先RETURN→SHORT的S_D_FULL，否则RETURN→RETRY的D_REC_R。实际为6个线性和3个继续动作比较；不换查询方向，不修改任何旧证书或Gate，不读取真核或真regret。

输入比较、完整来源加目标的必要投影计数及原上界先留存。分子仍为V235 Jeffreys联合M，分母为同样全部计数的L。只检验该canonical region，不把其他七族相交或新旧证书OR组合。无新采样、重放或远程数据拉取。

线性risk gap为dc−sc−4+8s−4d_DEL+4d_LOST。RETURN→RETRY的risk gap为d·(8r−4−retry_cost)，坏域等价h=r−a−b/d≥0，a=(4+retry_cost)/8，b=.05/8，d>0。前者为单纯形上线性半空间，后者为凸函数a+b/d的上图；logL在各行概率上凹。因此任意内部建议点和非负乘子λ，对f+λh的切线加完整概率域的线性支撑都给出全域坏likelihood上界，无需增加32格。

每个唯一计数/相关费用组合仅运行一次SLSQP建议：线性起点s=.9、d_DEL=.05、d_REC=.1；继续起点d=.5、r=.9。maxiter=500、ftol=1e−12，概率建议bounds为[1e−9,1−1e−9]，目标负logL除以总计数。建议界不限制证明的完整参数域。优化器成功、局部最优或搜索失败均不能决定科学状态，不追加起点或参数扫。

建议以F(str(float)).limit_denominator(10**9)有理化，各行精确归一化。严格坏核修复固定gap目标=.05+10**−6：线性保持D行并精确调整s，继续保持d并精确调整r。只有精确单纯形、gap>.05且M≤960L全部成立，才记录admitted_bad_kernel。修复不可行时不作坏核判断。

全域证书使用建议点的精确概率梯度与非负λ。线性取消s方向残差并在每行完整单纯形取支撑；继续λ=max(0,−∂f/∂r)，在[0,1]^2取残差支撑，仍覆盖全部d>0坏域。logL向上界与logM向下界采用原80位向外算术，严格logM下−全域上>log960上才为global_bad_null_excluded。否则无可行坏核就记unknown。完整计数、建议、修复及切线算术全部留存，不序列化巨大likelihood分数。

诊断最多正式运行一次；相同family、计数及相关费用可精确缓存。独立审计不导入本轮生产代码，复用已有独立投影/Jeffreys权重与100位向外logs，重算精确gap、M≤960L、凹约束梯度、合法乘子、全域支撑和严格判定。只核对V239有效输入/计数与原费用引用，不重验原批次或先前证书。
