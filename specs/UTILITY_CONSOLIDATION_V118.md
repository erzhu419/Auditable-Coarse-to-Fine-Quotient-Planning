# V118: source planning utility for fixed-candidate consolidation

V117's separate banks improved B/A-return control relative to shared trees, but its source-MSE selector never chose a split model. All learned controllers still trailed H2 in phase/query means. Freeze those findings and candidate parameters. Test whether paying for direct source planning validation improves selection on those four retained source histories. This is not a new training-history replication or an equal-sample-budget comparison.

Extract a source-only capsule from V117: source game summaries, fitted SHARED/SPLIT models, original selected models renamed MSE_SELECTED, their source selection/origins, router snapshots, fit and source-validation work. Exclude V117 outer predictions, control games and their outcomes. Copy the capsule and snapshot this implementation before new sampling. The V69 program, V115 router, V117 feature/tree budgets and V77 planner remain unchanged. No refitting, retrospective module reassignment or reuse of old outer trajectories.

UTILITY_SELECTED bootstraps to the retained A-end SHARED model. At B and A_RETURN, propose NEW_SHARED and NEW_SPLIT from that checkpoint and KEEP from this utility selector's previous selected parameters. Bind every candidate to the same current inherited router/module. Play four paired source game replicas for each candidate and each reward/risk_goal query:24 games per selection,192 overall. These are new training/selection interactions, not independent confirmation. Neither their spawns nor their outcomes update the router or tree parameters; only their terminal utility selects a candidate. Missing policy branches explicitly use H2 and keep the fallback cost.

Utility is unchanged: score/2048 for reward, score/2048−4*LOST+4*WON for risk_goal. Require the complete terminal candidate/query/replica roster and shared environment seeds. If any game is censored or missing, retain KEEP and mark that selection incomplete. Otherwise compute each query's mean over four replicas. A candidate is eligible iff neither query mean is lower than KEEP and at least one is strictly higher. Choose the eligible candidate with largest equally weighted query mean, exact ties preferring NEW_SHARED over NEW_SPLIT. If neither qualifies, keep the incumbent. No epsilon, variance-dependent extension, search or test-driven threshold.

Unlike V117, this criterion protects current query means, not every historical validation batch. It changes the objective and adds validation experience; no claim that criterion alone causes any improvement. Old-task retention is measured independently, not guaranteed by acceptance. Keep the complete source validation games, decision values, selector inputs, scores and choices. The frozen MSE_SELECTED path provides the previous rule's comparator without reselecting it on new outer results.
