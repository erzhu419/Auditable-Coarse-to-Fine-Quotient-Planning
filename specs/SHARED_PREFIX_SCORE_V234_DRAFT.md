# V234草案：共享前缀的条件动作比较

V233修复1/12旧失败，但仅保住7/12正对照。五个退化终态全部含RETURN↔RETRY阻塞；本阶段改变统计对象，暂不扩大付费预算。此草案已由[冻结协议](SHARED_PREFIX_SCORE_V234.md)具体化；保留作为设计来源。

记p为DETOUR_PASS的RECOVERY概率，q为RECOVERY_RETRY的DELIVERY概率，r为已知retry_cost。相同D前缀与operating费用精确抵消：

- goal：U(RETRY)−U(RETURN)=p(4q−r)。
- risk：U(RETRY)−U(RETURN)=p(8q−4−r)。

反向比较取负号。条件后续差h仅依赖R，必须用完整已付费R队列，不能按D长度截断，也不能只使用配对中D_RECOVERY位置的R结果。p和q均从原观测推断。

在同一全前缀事件上得到所需方向h∈[hL,hU]。若hU≤.05，只用0≤p≤1即可认证该方向完整策略差≤.05；尤其hU≤0时完整策略差≤0。否则再用同时有效的p∈[pL,pU]，在四个矩形顶点精确取max(p×h)，严格按原regret≤.05判断。不得将p替换为点估计。各事件可相关，联合覆盖使用共同预算。

实现前须冻结：原24个终态/策略、A/B继承规则、全前缀置信族及δ分配、与其他动作比较共同使用的事件集合，以及数值向外界。若保留V233其他比较，必须重新计入共同事件预算；不能将两个各用δ=.05的方法事后择优合并。

首轮仍零新增获取，先冻结全部证书，再评分和独立审计；报告全部查询资格及12个正对照的退化，不能只报告RETURN↔RETRY获证。同步保留7个SHORT↔RETURN风险阻塞：它们需要独立解决不同算子均值差的证据效率，不能由本分解推断已修复。资格不足时保留负结果，资格有效后再冻结新流生命周期与成本/质量条件。
