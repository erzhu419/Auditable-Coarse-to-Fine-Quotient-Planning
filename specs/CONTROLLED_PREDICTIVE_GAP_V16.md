# V16：竞争动作差距与提前停止

本协议在真实运行前固定。V15 均衡／定向重采的完整策略最优数仍为 453/480；定向对均衡 8 改善、15 退化，且重采增加成本。本轮改变获取决策的依据，并单独检验提前停止；不优化评分计算，不修改 V14/V15 留存。

## 固定输入与对照

沿用 V15 原 16 根、horizon、三个种子 832101–832103、十查询及原顺序和暴露标签。每方法 480 个查询场景。六方法为 full_state_empirical、exact_empirical_quotient、online_mass_bound（V14 BASE）、online_balanced_resampling（V15 BALANCED）、online_gap_continue、online_gap_stop。四 ONLINE 共 1920 棵历史树，执行次序按 (根索引+种子索引+查询索引) mod 4 循环轮转。

每根／种子重新付费构建一份原 V14 MASS_BOUND、最多 32 行的十查询 warm；无 Stage A128。BASE 直接使用它；转换成 V15 整数累计模型一次供 BALANCED 使用，另转换成 GAP 模型一次供两个 GAP 方法共享。各方法完整承担自己的 warm／转换费用，另列十查询分摊；物理账只计算实际发生的两次转换。两个 full 参考共享付费完整支持和全部行样本，预算与 ONLINE 不同。

保留 V15 明确编号的独立样本批：每批 256 次，第 0 批与 V14 相同，后续批使用 seed+1000000*batch_index 的原行种子公式。每条 ONLINE 路径最多 128 批，即 32768 个实际样本，包括 warm、首次和重复获取。本步配额为 floor((128−spent_batches)/h)，在到达当前 ACTIVE 状态时固定。相同上限不强求相同实际消耗，停止带来的差异是主要结果。

## 唯一新评分与两种停止行为

继承 V15 的整数计数、经验模型与增量价值缓存。新获取评分每次全量重算，局部误差尺度保持 r(s,a)=(原 V14 物理动作上界−下界)/sqrt(N(s,a))。终态采用原终值；未知行采用原物理上下界。已观测行分别计算 Q−=Σp(reward_weight*reward+V−child)−r、Q+=Σp(reward_weight*reward+V+child)+r；V−、V+ 分别取合法动作最大值，平局字母序，不裁剪到物理界。

incumbent 是原经验最大下界的执行动作；challenger 是其他动作中 Q+ 最大者，平局字母序。仅一个合法动作，或 Q−(incumbent)>=Q+(challenger)，标记启发式差距分离。此判断使用直接比较，不新增容差。

每批前计算同一份差距诊断。GAP_STOP 在分离时停止当前决策的获取，即使绝对经验价值区间仍未闭合；随后仍执行原经验最大下界动作。它只判断当前动作，下一实际孩子重新计算。GAP_CONTINUE 忽略分离，作为停止机制的直接对照。

未停止时，先使用原 V14 select_row 选择结构前沿。若结构选择无结果，则沿 incumbent 的下界续策和 challenger 的上界续策两路传播经验到达权重。已知行贡献为两路累计 reach*r；遇未知行只收集该前沿，贡献 reach*物理跨度，不穿越或读取未观测后继。两路同一行贡献相加，取最大贡献，平局按 (key,action)。零贡献不申请。只有一个动作时，CONTINUE 仍允许沿 incumbent 路径申请。每次请求统一收费一批，新支持触发原增量失效更新。

当前配额／路径预算耗尽、终态、差距分离（仅 STOP）、无可申请候选是不同停止原因；候选为空不能写成差距已分离。两个 GAP 方法除是否消费分离信号外，评分、分配与执行完全相同。BASE 与 BALANCED 调用原冻结执行器。

## 评价与完成条件

保持原历史评价器：先选动作，再由评价器读取所选真实行；兄弟历史独立，实际转移不加入独立采样。全部当轮历史固定后再计算真最优标签。随后只读 V14 原结果核对 48 个初始前缀和 480 棵 BASE 树，并只读 V15 gzip 核对 480 棵 BALANCED 树及根后果，要求语义精确一致。旧数据不免费进入当前规划。

主要配对为 STOP vs CONTINUE，分离提前停止效应；另列 CONTINUE vs BALANCED、STOP vs BALANCED、STOP vs BASE。保留每项完整策略 reward/failure/success/value、首动作／完整策略最优、所有退化、旧 8 项及旧 5 项见证，按原根／family／split 汇总。不得以相同最优总数代替逐项比较。

记录每节点的差距诊断、停止原因、请求及实际批数；给出期望／最大样本、不同观测行、独立／十查询分摊成本。新增差距评分、未知前沿获取、计数更新和 query clone 全部收费；兄弟反事实 clone 只计物理审计。全轮物理成本包括共享准备、所有历史的真实样本、full 支持／构建、真值评价、基线核对及压缩；内外层计时不重复相加。

针对性测试检测挑战者／下游／未知前沿被遗漏、分离与无候选混淆、停止与继续规则不一致、样本预算和转换归因错误。测试通过后仅运行一次冻结名册，不根据结果改规则或重跑。固定导出同 V15 的三组 GAP_STOP 历史（spawn2/832101 十查询、crossing3/832102 risk5、crossing2/832102 四个 goal 配对查询），使用已有格式在新进程重放，与当轮树比较。完整数据无损 gzip 留存，文字结果保持简短。
