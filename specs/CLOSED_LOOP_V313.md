# V313 — closed-loop natural-game policy evaluation and improvement

V312 supports first adaptation, joint active-two-table contribution and frozen
context reuse. V306 only collected one cohort with a frozen first-adapted policy;
V307's fixed old/new replay harmed it. Test whether an updated policy can acquire
new factual outcomes and improve again. No old-policy return is relabeled as
a current-policy target and no old target data is a new fitting input.

## Frozen experiment

Use the four audited V312 SOURCE value parents and shared deterministic dynamics.
Reuse SOURCE physically; retain its seven acquisition/compute cost fields
economically. Collect 16 new lifecycles, four per parent (parent=life%4).
This is a development mechanism experiment, conditional on the four sources.
No full-pipeline or independent source-population confirmation is claimed.

First acquire new A (true p_four=.1) then B (.5), each with V309 confirmed
context detection and 131,072 raw SOURCE-carrier observations. Require distinct
actually confirmed initial banks; if that precondition fails retain the cohort
and block support, without dropping or substituting a lifecycle. Fix each
bank's first complete-game chronological 80% FIT belief for every actor and
evaluation. Known subsequent task batches address the bank identified in this
initial observed route; this experiment supplies task/batch boundaries.

Fit FIRST_LOCAL and FIRST_LINEAR once on exactly the same fresh initial facts
with unchanged V301 LOCAL and V311 LINEAR_WIN2, alpha=.0025. Keep both frozen.
Copy their actual weights into private updating branches CLOSED_LOCAL,
FIXED_LOCAL and CLOSED_LINEAR. Each performs two scheduled consolidation rounds.
FIXED_LOCAL always collects with FIRST_LOCAL version0. Each CLOSED branch
collects with its own previous updated H2 head. Freeze both head arrays for the
whole cohort and update only after it closes. Record actual inactive-bank history.

Process A_R1, B_R1, A_R2, B_R2. Each collector pays exactly 65,536 raw per batch,
including initial tiles and unfinished tails. The two LOCAL round1 collectors
are identical, so acquire their SHARED_LOCAL cohort once physically and charge
it economically to both; fit both private learners independently. LINEAR uses
its own cohort. Round2 uses three separately acquired cohorts. Pair the seeded
raw streams among collectors at each life/task/round. Any natural overshoot of
initial detection remains paid. Do not fit a CUTOFF label; retain its tape and
block complete-game scientific support.

Chronologically split each cohort's complete games 80% FIT/20% HELDOUT. For
each task/round set the supervised-state quota to the minimum eligible
nonwinning FIT-state count across actual collectors. Select each chronological
eligible prefix with a deterministic mask; retain full original game endings,
reward suffixes and WIN/LOST labels even if the mask stops inside a game.
No heldout or unfinished tail state is fitted. Each branch processes the same
quota once using its existing game-start residuals/address normalization.
Count discarded raw, varying address writes and actual CPU separately.

reward plus that head's combined afterstate prediction, with analytic WIN +4;

first-maximum ties. These are same-head planner contrasts, with no additional fit.
There are 13,312 new physical evaluation games; retain every outcome.
