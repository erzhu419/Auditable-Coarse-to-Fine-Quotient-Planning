Predict their observed R/F/S records with CURRENT MIXED/CONTEXT using the frozen current router estimate. Save immutable A_END and B_END consequence parameters; at A_RETURN also predict the same new cases with those earlier parameters, again at the current router context. Old context estimates are not substituted into this comparison.
