# V5：试采驱动的动作差距不确定性与等预算定向采样

本开发协议在 V5 科学比较执行前写入。目标是在固定精确经验商构建方式下，比较试采驱动的定向追加观测与同总预算均匀采样。V4 的错误、重复根和非单调采样曲线作为已暴露开发依据保留。

## 试采与动作差距诊断

每个实例、种子首先对每个合法状态／动作行读取 64 次观测，得到经验核。三个种子为 `832101,832102,832103`。只用该试采经验核规划 V3 的六个构建查询：收益权重 1，失败惩罚 `0,0.05,0.2,1,5`、目标奖励 0，另加失败惩罚 1、目标奖励 1。

对每个已覆盖活跃状态，比较名义最优动作 b 与每个其他合法动作 a。动作差距为 `g = Qhat(b) - Qhat(a)`。两条反事实首步之后均执行同一个名义经验策略。

沿经验转移传播两条首步策略的**带符号到达概率差**，得到各状态／动作行的系数 c。相同后续路径的系数先相加抵消，再计算平方。每一经验行用观测到的 `Y = reward_weight × reward + Vhat(next)` 计算无偏样本方差 s²。动作差距的线性化方差估计为：

`variance_gap = sum(c[row]^2 * s2[row] / n[row])`。

若标准误差为正且 `g <= 2 × sqrt(variance_gap)`，将该动作对标为排序不稳定。零经验方差不被当作已知无误；它只是不触发这项试采诊断，后续仍有均匀观测预算。`1e-10` 仅标记数值并列，不扩张两倍标准误差规则。

该诊断基于固定名义策略和经验概率的线性化，估计值与方差使用同一批试采。它不具有本轮已证明的置信区间覆盖率，不是风险证书。

## 固定分配规则

每个经验行的权重首先累加所有不稳定动作对的标准化方差贡献：

`A[row] = sum(c[row]^2 * s2[row] / variance_gap)`。

所有活跃状态、六个查询中的动作对等权进入这项和；没有额外的根状态权重。定向分配权重取 `sqrt(A[row])`。

设合法动作行数为 R，最终等预算水平 N 为 256 或 1024。两组最终均读取 N×R 次逻辑观测：

- 均匀组：每行 N 次。
- 定向组：每行至少 N/2 次，剩余 N×R/2 次按上述权重分配，使用最大余数法及固定动作行排序得到整数计数。若所有权重均为零，退回均匀分配。

两种最终预算的分配都由同一个 64 次／行的试采结果一次确定。在之后的 256／1024 阶段不重新选择权重，不使用评估结果调整分配。该方法是一次试采后的定向采样，而非持续在线自适应。

各行的随机流固定，两组共享试采，并在相同的行内前缀位置使用相同观测。试采之后各分支分别向 256 和 1024 总预算推进。分配不同意味着最终观测集合不同；匹配的是总预算和随机前缀，不能称为两组读取完全相同的最终样本。

每组的逻辑观测预算、试采共用次数、分支实际随机抽样调用数分别记录。复制分支随机流所重新生成的重叠观测计入实际调用，不能把物理执行成本藏在逻辑预算中。

## 构建、评估和成本

两种采样分配均调用零容差 `build_quotient(empirical)` 构建精确经验商，再分别规划十个查询。四个未参与分配的探测查询为失败惩罚 `0.1,0.5,2`、目标奖励 0，以及失败惩罚 0.5、目标奖励 2，收益权重均为 1。

精确环境只用于生成观测、最终最优参考和冻结策略审计。采样分配只接受经验核、观测计数和六个查询；不读取精确概率、真实最优动作或棋盘特征。每个实例的各组计划先固定，再生成精确评估结果。完整状态经验模型作为每种分配下的辅助同信息量比较，相关成本单列。

比较根动作、根部完整策略目标损失、失败率预测，以及闭包中全部活跃状态的策略质量和严格查询切换。按六查询库与四探测查询、来源及种子分别保留结果。定向组的试采规划、方差扫描、反事实系数传播、整数分配和存储维护均计入成本，再加观测、模型构建、最终规划、预测和真实环境审计。

在分配已固定之后，另将试采的不稳定标记与真实最优动作集合比较，报告“标记且当前动作错误”“未标记但当前动作错误”“标记且当前动作正确”。动作恰好正确不等于不确定性标记是错误的，不把该统计误写成置信覆盖率。

只有这一项科学比较运行，不与其他计算实验并发。各阶段和模型的完整成本保留；若定向分配降低逻辑样本下的损失但计算开销更大，将两项分别报告。

## 验证和判断

针对性测试检验共享未来路径抵消、后续转移方差能够影响上游分配、总预算与逐行最低观测数、零经验方差的均匀退路、分配不读取未来阶段观测、探测查询不参与分配，以及完整状态的冻结策略审计。源码检查确认没有精确评估向分配器回流。

运行保留全部 14 实例及失败，不按结果换种子、改两倍标准误差规则或改预算比例。根暴露和闭包重叠另列；若新根仍缺少独立查询冲突，将其保留为任务设计限制。

定向分配是否值得继续，以同总观测预算下的实际策略后果和完整成本判断。未通过的来源、未被标记的错误及风险预测失准都保留。U005 科学 FAIL、U006 未启动及旧 V1–V4 结果不变；本轮仍不是可迁移编码器或正式科学 Gate。
