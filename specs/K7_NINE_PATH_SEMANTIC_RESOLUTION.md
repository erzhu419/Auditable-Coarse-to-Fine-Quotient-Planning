# K7 nine-path semantic resolution boundary

**Milestone:** `V0-110B-2E-0`

**Contract:** `2.0.10`
**Profile:** `construction_shared_resource_resolution_v2`

## Purpose

This construction slice freezes the exact live evidence contract for the nine
shared-resource paths before any numeric value may enter formal accounting.
It prevents the existing structural V1 receipts or a broker/worker self-report
from being relabelled as verified actual work.

## Nine exact sources

The official catalogue joins every path to the V6 counter registry metadata,
one distinct source family, required canonical component schemas, provenance
obligations and one fixed semantic verifier key:

| Path | Exact live source |
|---|---|
| `common.hash_invocations` | closed hash-event transcript, purpose registry and loaded-site coverage |
| `common.integrity_checks` | complete integrity-obligation registry/transcript and loaded sites |
| `common.protocol_checks` | complete protocol-obligation registry/transcript and loaded sites |
| `io.mounted_bytes_peak` | unique-payload mount visibility intervals |
| `io.output_bytes` | exclusive durable eight-role output fixed point |
| `io.read_bytes` | exact read-transfer journal and charge registry |
| `io.staged_bytes` | exact staged-transfer journal and charge registry |
| `memory.working_bytes_peak` | pre/post reads from the same retained `memory.peak` OFD after descendant-free reap |
| `process.launches` | broker lifecycle journal joined to PID, pidfd, SCM credentials, direct reap and no-spawn proof |

Every path requires the same occurrence identity and closed inclusive cutoff;
path-specific provenance adds authenticated sequence, source-site/registry
coverage, transfer-key coverage, exclusive writer, unique visibility,
same-OFD/cgroup emptiness or PIDfd/SCM/no-spawn obligations as appropriate.

## Typed pending boundary

A V2 live envelope can carry only canonical raw evidence components and their
schema, artifact identity, digest and byte count. It has no reported-value
field. Arbitrary mappings, V1 receipt/closure instances, V1 schemas and bytes
that explicitly deny semantic/numeric authority fail closed.

The verifier always returns exactly nine typed resolutions in official path
order. Missing sources and components are enumerated. Even a structurally
complete component set remains
`PENDING_LIVE_EVIDENCE.SEMANTIC_REPLAYER_NOT_INSTALLED` until its fixed
path-specific verifier independently recomputes the exact integer and all
provenance obligations.

## Claim boundary and successor

This slice deliberately installs no semantic replayer and exposes no
`CounterRecord`, `WorkVector` or `ComparisonVector` materializer. Its
catalogue fingerprint and resolution documents are internal diagnostics, not
formal content-addressed accounting artifacts.

The successor must produce the live broker envelope, implement all nine exact
replayers, close the remaining 193 native/static/derived V6 paths, and only
then atomically materialize the complete 202-record occurrence bundle and its
182-term eight-axis projection.
