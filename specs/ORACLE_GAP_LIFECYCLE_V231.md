# V231：已知类型下的生命周期动作差获取

本阶段隔离类型内精度问题，检验重新分配整个生命周期的采样预算是否有效。固定世界life0、1、2，分别覆盖B变化SHORT、DETOUR、RETRY；每个完整运行A24→B24→A′24。两臂`ORACLE_BALANCED`、`ORACLE_GAP`都收到真实类型、变化算子与B到A对应关系；没有真实转移概率或最优动作输入。

来源及目标全部使用新观察。来源seed=`262000+(life*6+slot)*3+op_index`，A的3×3×384及B的3×3×128由环境共采，各臂分别收费4608/life。目标seed=`263000+(life*78+index)*3+op_index`；两臂各有独立读游标，读取相同潜在流的各自前缀，每次实际读数分别收费。最大目标观察72×384/臂/life，batch16；不复用V229或V230的目标前缀。

每批实际观察立即加入本臂真实类型的累计池。A在B期间保持原样，A′恢复A池。B仅继承未变化A算子的来源和A末期池CS；变化行不继承。每个row的区域是来源、当前池与当前member联合CS的交，B的未变行再与A约束相交。δ按每臂每life分配：216个member算子流共.025、9个A池流共.0125、9个B池流共.0125；threshold8640、720、720，仍为.05。来源是对应池的初始前缀。

两臂用同一actual-count Jeffreys点后验、同一纯查询策略选择、联合CS证书和安全执行解。查询误差.05、目标效用2、执行risk.05保持不变；仅在目标获证或不可达获证、且三查询全部获证后停止，否则到cap384。当前查询策略在点后验上选择，未更改为其他策略语法。

均衡臂补采当前成员观察最少的算子。差距臂对未获证查询的阻塞策略比较，固定其他行的当前后验、将本行在置信盒/simplex顶点间变化，计算utility差span；加上未解决执行目标的驱动span。按`1−sqrt(n/(n+16))`预期收缩加权，n是该行实际累计点计数（B未变行包含A）。这是获取启发式，不是新的置信公式或虚拟观察。停止与证书只使用实际观察。

主要读取每臂的晚期B（index42..53，共36）及A′（index54..77，共72）查询获证、联合完成、总来源＋目标费和模型计算时间；各life分别报告。以此前75%质量要求作为阶段可行性参照（晚期B27/36、A′54/72），不把三条布局的隔离诊断称为新科学Gate或总体优势。若已知类型仍缺证，先检查终态区域的可行排序反例，再决定调整统计契约；不继续无目的获取器微调。
