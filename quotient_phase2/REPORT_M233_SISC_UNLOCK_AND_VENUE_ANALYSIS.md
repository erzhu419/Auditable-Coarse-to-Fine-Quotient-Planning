## 一、为什么与本文最接近的那几篇先驱工作能发 NeurIPS / ICML / AAAI / ICLR？

### 1.1 精准文献刊物核查（避免错位参照）

把与 Phase-II 技术主线最接近的层级/边界组合线性可解马尔可夫决策过程（LMDP）论文逐一核对真实发表会议，可以看到一条非常清晰的学术演化轨迹：

- **Todorov (2009)**, *Compositionality of optimal control laws* —— **NeurIPS 2009**（首次提出 Cole–Hopf 边界期望度线性叠加原理）；
- **Saxe, Earle & Rosman (2017)**, *Hierarchy through composition with multitask LMDPs* —— **ICML 2017**（将线性组合拓展到多层任务层级，并与认知神经科学中的海马体网格细胞表征结合）；
- **Jonsson & Gómez (2016)** —— **ICAPS 2016**；以及**真正与 Phase-II 问题设定最贴近**（多房间分解 + 出口边界值组合 + 不显式存储全网格策略而隐式恢复全局最优原始策略）的 **Infante, Jonsson & Gómez (2022)**, *Globally optimal hierarchical reinforcement learning for linearly-solvable MDPs* —— 实际发表在 **AAAI 2022**（**并非 NeurIPS / ICLR**）。
- 至于 **2023–2025 年真正录用 NeurIPS / ICLR 的近邻工作**（如 Quasimetric RL、Hilbert / Successor Representations、Diffusion / Schrödinger Bridge Compositional Planning、Offline Linear MDP State Abstraction），它们与已知算子网格求解器处于完全不同的审稿评价维度。

### 1.2 决定“能上 NeurIPS/ICLR”与“最适合 SIAM SISC / JAIR / IEEE TAC”的四个本质原因

1. **`0 -> 1` 概念范式红利 vs. `1 -> 1.5` 数值算子与严格误差认证（学科主场差异）**
   - Todorov (2009) 与 Saxe et al. (2017) 解决的是“**非线性随机最优控制律居然可以像线性基函数一样做零重训组合**”这一概念性发现（且处于 2009–2017 年表格型/网格验证即可发表顶会的时代）。
   - 一旦“房间内部消元 + 门框边界组合”本身已被 Todorov (2009) 和 Infante et al. (AAAI 2022) 建立，Phase-II 进一步攻克的**三维 $9\times 9 \sim 11\times 11$ 门框截面维度爆炸、粗化分块带来的 $O(1/h^2)$ 接缝拉普拉斯奇异性、M-矩阵保序一步光滑次解 $A z_{\mathrm{sub}} \le 0$ 以及 IEEE-754 `float64` 闭环策略四重不等式 $L \le V^* \le J^{\hat{\mu}} \le U$ 认证**，本质上是**数值偏微分方程 / 区域分解（Domain Decomposition） / 科学计算**领域的硬核贡献。这类贡献在 **SIAM Journal on Scientific Computing (SISC)** 审稿人眼中是极具分量的核心突破，但若直接投给当下以深度学习/表征学习为主的 NeurIPS/ICLR 普通审稿人，极易被简单归类为“已知稀疏线性系统上的数值求解器优化”。

2. **输入先验：`未知动力学下的轨迹交互学习（Learning）` vs. `已知稀疏矩阵与占据网格规划（Planning）`**
   - 当今 NeurIPS / ICLR（2024–2026）对 RL/Planning 论文的隐性硬门槛是 **Learning**：未知状态转移、从采样轨迹或高维连续观测中学习表示，不能依赖给定的轴对齐房间切面规则（即便 Infante et al. AAAI 2022 也在未知房间内用采样轨迹在线估计子任务，并与 Q-learning / MAXQ 对比样本效率）。
   - Phase-II 的 3D 求解器虽然拟合了 48 个噪声探针的 GP 风险/漂移场，但下游规划器的直接输入是**显式构建好的三维稀疏 M-矩阵 $A$ 与轴对齐二值占据网格 `free_3d`**（`0.58 * median` 截面电导检测），核心算子是 `SuperLU + Schur Complement + Howard + BiCGSTAB`，不包含未知动力学探索或端到端商表征学习。

3. **Baseline 诚实度带来的“视觉加速倍率差”**
   - 许多 ML 顶会论文对比的是朴素 Flat Value Iteration 或从零训练的 Model-Free RL，曲线动辄呈现 `10x–100x` 差距（若将我们的求解器对比每查询全局 `spsolve`，同样有 **`>20x`** 加速；对比全局因子复用 `SingleLU_GoalCapacitance` 也有 **`2.72x–4.74x`** 加速且省 `26%–28%` 内存）。
   - 但为了做最严苛的科学归因，Phase-II 专门构造了共享**完全相同**的零提示房间分解、27 个局部 `SuperLU`、完整目标环电容和 $L_0$ Lyapunov 权重的贴身最强基线 `MatrixFree_ExactSchur_Krylov`，将“纯门框界面自适应粗化 + 缓存”的净收益诚实地剥离出来（解锁后为 **`24.4%–31.6%` / `1.32x–1.46x`**）。SISC / JAIR 审稿人高度欣赏这种剥离混杂因素的严谨对照，而大同行 ML 顶会审稿人往往对 `1.4x` 的表面数字不够敏感。

4. **直冲 NeurIPS / ICLR 的精确跃迁路径（已于 `learned_portal_phase3/` 完整实现）**
   - 保留本文建立的“无接缝正定门框积分核 + 闭环四重不等式遗憾认证”理论底座，**去掉轴对齐占据网格先验与显式矩阵 $A$**，直接从智能体在未知环境中的交互轨迹（或非结构化图 / 连续状态观测）中**端到端学习决策充分的瓶颈商空间算子（Learned Decision-Sufficient Portal / Successor-Green Abstraction）**，同时给出样本复杂度与闭环策略遗憾上界——从而由“科学计算求解器论文（SISC）”自然跃迁为“表征与强化学习理论算法论文（NeurIPS/ICLR）”。

## 二、`路线 2` 执行结果：SISC 算法瓶颈解锁、全新 $n=12$ 确认集与论文全面升级

在不触碰任何历史冻结代码与 10 份历史 JSON 档案（`m20..m232` 全部通过字节级 SHA-256 校验）的前提下，在独立新模块 `quotient_phase2/m233_sisc_subportal_quadtree.py` 中根治了系统审阅定位出的三大工程瓶颈（**所有超参数严格仅在 `Dev 61000..61005` 上锁定，零窥探测试集**）。

### 2.1 系统审阅定位的根因回顾（`M2.3.2` 剖面诊断）

单图只读阶段计时剖面（`seed=63000, K=24`）揭示了 `M2.3.2` 未过 `20%` 工程门限及 `35^3` 倒挂 `-12.15%` 的精确工程根因：
- 在 `35^3` 上，`Howard` 稠密迭代占总查询时间的 **`58.1%`**（每轮均冷启动重算 `Sys_bar` 与三次独立 `v_lyap` Howard 循环）；
- 在 `47^3` 与 `59^3` 上，整扇门框一刀切升级（`L2: 16` 块直接跳至 `L3: 64` 块）频繁撞上硬编码上限 `m >= 480`，触发昂贵的全界面 Krylov 缺陷回退（`47^3` 触发率 `20.8%`，`59^3` 触发率高达 `42.4%`；未触发回退的任务原本净节省已达 **`40.2%–50.3%`**）。

### 2.2 三项核心算法升级（数学证明与代码实现完全闭环）

1. **自适应子门框四叉树切分（`L0..L4` 直达精确单点，`m_cap = 768`）**  
   废除 `M2.3.2`“整扇门框一刀切升到 `L3` 且在 `m >= 480` 硬截断”的粗糙策略，仅对高伴随振荡（$\psi_j \cdot \mathrm{osc}_{B_j}$）的子块按需分裂直至 `L4` 单节点，将全界面 Krylov 缺陷回退率砍低 **$3\times \sim 13\times$**（`59^3` 回退率从 `42.36%` 降至 **`13.89%`**，`47^3` 从 `20.83%` 降至 **`4.51%–6.25%`**，`35^3` 降至 **`0.69%`**）。
2. **嵌套切口 $L_0$-Lyapunov 不变性复用 + 热启动 Howard（论文 Proposition 4(1)）**  
   利用任意子门框四叉树切口 $\mathcal{B} \prec \mathcal{B}_0$ 满足 $w_{\mathrm{lyap}} = L_{\mathcal{B}_0} v_{\mathrm{lyap}}^{(0)} \in \mathrm{col}(L_{\mathcal{B}})$ 的代数性质，在第 `1..9` 轮直接复用第 `0` 轮（$<0.2\text{ ms}$）求出的正 Lyapunov 见证做外推松弛平移（仅在 `~0.1%` 跨多房间极小值下溢时局部刷新），消除了每轮重复的 $O(m^3)$ `v_lyap` Howard 求解。
3. **单位分解 $(k-1)$ 子块精确守恒（论文 Proposition 4(2)）**  
   利用 $\mathbf{1}_{B_{\mathrm{par}}} = \sum_{q=1}^k \mathbf{1}_{B_{\mathrm{ch},q}}$ 与算子线性性，缓存未截断父块响应，每次 $k$ 子块分裂仅需对 $k-1$ 个子块做房间 LU 回代（$2\times 2$ 分裂精确节省 **`25%`** 缓存未命中 LU 回代），实测 `L0 -> L4` 递推误差 **`max |K_pou - K_direct| = 9.71e-17`**（机器精度级等价），使 `47^3` 每张图的运行期房间 LU 回代列数从 `M2.3.2` 的 `9,010.2` 进一步降至 **`5,950.3`**（再降 **`34.0%`**）。

### 2.4 关于负结果的定性闭环

1. **已消除的纯工程负结果**：`47^3 / 59^3` 未过 `20%` 门限及 `35^3` 倒挂 `-12.15%` 已被实证确认为工程启发式瓶颈。解锁后 `35^3` 转为 `+9.65%`，`59^3` 跃升至 **`+28.77%`（`PASS`）**，全新确认集 `64000..64011`（$n=12$）上 `47^3` 达到 **`+31.58%`、`12/12` 全胜、`p = 0.00815`（`PASS`）**（对比全局复用 `SingleLU` 加速 **`2.72x`** 且省 **`26.0%`** 内存）。
2. **明确保留为数学/体制适用域边界（Regime Characterization）的负结果**：
   - 2D 极小门框（`M2.2`，总门户节点 $n_\Gamma = 285$，精确稠密 Schur 仅需 `<1ms`）；
   - Continual 每轮仅 $K_{\mathrm{ep}} = 6$ 次查询的短摊销窗口（`16.51%` 显著正收益但未跨过 `20%`，与缓存冷热斜率一致）；
   - 正交 SVD 基底产生 `30.7%–50%` 负值破坏 M-矩阵单调性（`Exp 5`）；
   - 全网格双线性 DWR 因全局 `splu` 重分解导致成本倒挂（`M2.1`）。
