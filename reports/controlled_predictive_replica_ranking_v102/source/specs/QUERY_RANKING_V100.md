# V100: matched query-conditioned candidate ranking

Freeze before main fitting or evaluation. V99 made learned continuation matter to choices without reliable utility gains. Test a decision-level ordering objective against scalar utility regression using exactly the same inputs and model capacity.

- Keep V98 lives9/10, R8/R4 acquisitions and budget ages256000/512000. Accept exactly the original complete five-option terminal blocks, excluding entire incomplete roots. Extract each option's mean terminal R/F/S difference from H2, then query utility (reward R; risk R−4F+4S). H2 target0. Equal weight per complete root; do not reuse the old continuation-row length or boundary weights. Hold out episode%5==4 and exclude future episodes from all fitting and normalization. No new real training acquisition; charge inherited source, heldout and incomplete work once.
- Each accepted root receives32 paired four-action model prefixes for all five candidates. Training seed=210000000000+life*10000000+episode*1000+query_index*100, plus replica0..31; planner seed adds10^12. These model streams are independent of terminal labels. Shared root addresses match between R8/R4, but both executed computations are charged. Save compressed prefixes and compact root examples.
- Each candidate has121 decision-time features:36 observed-root features, mean74 paired candidate/H2 boundary features, mean3 prefix R/F/S differences, five option indicators, and three query utility coefficients. Never use terminal trajectories or labels as features. Mean and standard deviation are fitted on eligible training roots/candidates only; zero standard deviations use1.
- Shared scalar network `v^T tanh(Wx+b)`,16 hidden units, no output bias,1968 parameters. Pool the two queries with the explicit query coefficients. Subtract the H2 score before deployment; all candidates including H2 are compared with strict greater-than in frozen option order. Both losses have the same initialization (NumPy default_rng10001, normal standard deviations sqrt(2/(121+16)) and sqrt(2/(16+1)), zero bias), full-batch Adam1000steps, rate0.01, betas0.9/0.999, epsilon1e-8, plus0.001 times mean squared parameters. No tuning, early stopping or checkpoint selection. Save initial/final objective and final gradient norm.
- UTILITY_MSE minimizes squared H2-centered scalar error averaged over roots×5. PAIRWISE_RANK uses all10 unordered candidate pairs per root: `abs(delta_u)*softplus(-sign(delta_u)*(score_i-score_j))`, averaged over roots×10. Label ties have zero weight; prediction ties get half error in descriptive ordering metrics. Ranking scores are ordinal and are never reported as calibrated utility or R/F/S predictions. Record empirical selected regret and weighted misordering; heldout metrics are descriptive only.
- Fit both objectives independently at both ages and both allocations:16 new neural fits,16000optimizer updates; no Bellman/tree fits. Relative to V99 both inputs and model family change, so only the matched RANK−MSE comparison isolates the objective. Retain H2 as behavioral baseline and prefix-only as diagnostic control.
- Ten natural methods: H2_ONLY, PREFIX_ONLY_DIRECT, R{8,4}_{UTILITY_MSE,PAIRWISE_RANK}_DIRECT and their FROZEN_HALF versions. Eight new games/query/history/method=320games. Same first-trigger fragment/H2 execution,2000-step cap. Natural seed=10090000+life*100+replica; actor seed adds1000000. Deployment-prefix seed=200000000000+life*10000000+query_index*1000000+replica*1000. Nine direct methods share32replicas×five options×four actions; at most184320deployment model transitions,288selector calls. Prefix-only computes the same candidate features but makes zero neural predictions; count this work.
- Frozen16 contrasts: RANK−MSE at both allocations/ages; each full model minus own half; each full model minus H2; RANK minus prefix-only at both ages. Report per-history and equal-history paired means. No efficacy intervals or scientific Gate. Record choice agreement and actual changed choices.

Retain original deployed scores/choices before references. No selector rerun, refit, root replacement or outcome-based inclusion. Report selected reference utility and all-ten-pair weighted ordering error; only MSE/prefix models have utility-MSE diagnostics. Best-reference gaps use noisy finite estimates, not known true regret.
- Retain source snapshot, models, gzip traces, fitting/data costs and terminal attempts. Training model-prefix work, natural model-prefix work, real natural/reference transitions and inherited acquisition are separate. Focus tests on analytical gradients, root/episode isolation, incomplete block exclusion, label-independent features and model-age/prefix wiring.
