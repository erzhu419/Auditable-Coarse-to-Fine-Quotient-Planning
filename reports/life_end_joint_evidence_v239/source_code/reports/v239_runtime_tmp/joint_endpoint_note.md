# V239：保留来源证据的生命周期终点

每个必要投影行固定Jeffreys/Dirichlet先验，训练计数s、验证计数t，Q=M(s+t)/M(s)。
精确恒等式：`[M(s)/L(s)] × [Q/L(t)] = M(s+t)/[L(s)L(t)] = M(s+t)/L(s+t)`。
这恢复整个已付费行的联合证据；不能把独立重新认证的来源和条件结果作OR。
沿每臂自己的原获取顺序，行更新因子为当前Dirichlet预测概率/真行概率，条件期望≤1。
A事件使用对应A来源、同身份全部本臂A/A_RETURN目标，忽略B。
B变化行使用B来源及同B身份全部本臂B目标，忽略A和A_RETURN。
B未变行使用映射A来源、切换前本臂同A身份目标、B来源及本臂同B身份目标，忽略A_RETURN。
未变行的A/B真行核相同；来源及目标均在原实际时点更新，只计一次，不要求各行训练同时结束。
其他臂的目标、长度和停止消息不进入本臂过滤族；不相乘两臂的耦合事件。
八投影×A/B×三类型仍为48事件；T960给出每life/arm共同覆盖至少95%，不声明六者整体95%。
