# V65：新图上的概率复用执行对照

冻结于 2026-09-12，主实验生成图之前。前提为 V64 完整通过独立核对，保留全部查询的动作、Q 和逻辑搜索，且两步规划配对计时完整。

## 固定设计

- 新生成 64 张有向 ER 图：15 节点，`p=1.5/14`，种子 `650000..650063`；使用冻结 V43 生成器，每图只生成一次。
- 每图预算 K=2、环境时域 T=3、32 次传播重复。BASELINE 调用冻结 V59，REUSE 调用冻结 V64；均为两步前瞻，每次决策冷启动。共 128 块、4,096 条轨迹，实际执行一次，不作计时预热。
- 每图两个变体相邻运行；偶数图索引 BASELINE 先，奇数图索引 REUSE 先，各 32 图。每回合种子 `61000000 + graph_id*1000 + replicate`；决策后按排序边抽取同一传播随机流，物理过程直接复用 V61。
- 单块上限：2,000,000 次动作估值、100,000 次决策、60 秒；主运行整体上限：6,000,000 次动作估值、300 秒。整体预算覆盖来源读取、快照、建图、准备、执行、清理和输出；检查发生在块前以及每次已付费决策后。上限为软上限，最后一次决策及留存可超过上限。整体限额是本轮两个两步规划器的固定预算，不与 V63 的一步加两步预算相等。
- 达到块上限保留已付费决策且不再传播；partial 回报为 null。整体耗尽后保留未执行后缀，不续跑补齐。

## 比较与计费

在新留存状态上以独立 V62 局部 Bellman 核对器重算 Q 和原版逻辑工作量。REUSE 的逻辑概率项数为 `actual_target_probability_evaluations + analytic_probability_terms - terminal_probability_cache_misses`；另检查缓存计数分区。相同输入、输出及逻辑计数只独立核对一次，再按变体分别重放真实传播和实际计数。

按图与回合严格比较动作、Q、计划值、逻辑搜索、状态和回报；任何改变都令保留结论失败。完整成本证据要求 128 块完整且独立核对、保留均通过。每图每变体成本为 `prepare_gc_seconds + wall_seconds + cleanup_seconds + serialization_seconds`，其中最后一项是轨迹序列化及 flush；case/manifest 写盘、日志和公共来源/建图等费用包含在整体运行时间，单独列出，不任意分摊到变体。

主要描述量为 64 图合计 REUSE/BASELINE 成本比；另列每图快慢数量、两个先后顺序分层和决策加清理成本比。图级 log 成本比的 t 区间（df=63）取指数，仅作这次跨图配对计时的近似描述，不新增速度 Gate。每图变体只执行一次，不能推断跨运行稳定性。回报相等仅说明本轮观测轨迹保持。

## 留存与边界

输出 `reports/lmta_probability_execution_v65/`，含协议/来源快照、图、块、完整或截断轨迹、独立查询证书、分析及成本。开发测试单独留存费用；主实验与独立分析各执行一次。旧实验与证书不重跑，无 RL 更新、MCTS 或全策略精确评估。U005 的 FAIL、U006 未启动和 V62 截断保持原状。

完成后依据新图保留情况和总成本判断是否把 REUSE 作为两步规划的候选默认实现；若总成本优势不明确，记录原因，后续实验另行冻结。
