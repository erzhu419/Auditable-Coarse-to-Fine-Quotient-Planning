# V249冻结：共享S/D补采的获取时机

前置V248 complete、独立valid且48端点/96分类完整。V248在两臂21/24、24/24端点发现R经验中心下的全域坏核；原SHORT决策和终态区域的获证上限49/72、48/72低于54。本阶段直接获取S/D机制证据，不再调单批评分；这是已知类型/变化接口下的结构资格实验，不是一般战略学习。旧失败、原Gate及U006未启动状态保留。

新完整A24→B24→A_RETURN24生命周期，life0/1/2，每臂216、合计648决策。三臂BEFORE_SHARED、DEFERRED_SHARED、REBUILD；前两臂使用ONE_WAY核心，强REBUILD沿用V243定义：B不继承A，仍累计自己的A/B池并在返场使用自己的A池。各臂都使用原V231获取、原证书、三查询AND、停止和WAIT回退，无旧目标或旧前缀选择。总预算14144/17072/17168，来源4608/life、batch16、member cap384保持原样。

两个补采臂固定每原生A类型SHORT_PASS、DETOUR_PASS各128次（384/3），3类型总768/life；不采RETRY。该配额只取公共固定cap，不依赖真概率或本轮结果。BEFORE在index54之前按identity0..2、S/D顺序读取全配额；DEFERRED在每类型首个返场目标终态与执行决定留存之后读取该类型配额，即使该目标已经获证或回退也照付，不修改它的答案。REBUILD不额外补采。两补采臂从生命周期开始都预留完整768，目标可用预算=总预算−4608−历史普通目标费用−768；未读补采是预留，已读补采才记实付，不重复扣款。

来源基数288000，seed=base+(life*6+slot)*3+operator；普通目标基数289000，seed=base+(life*78+index)*3+operator。补采基数290000，seed=base+(life*3+identity)*2+S/D序号，独立于目标流，持续读取offset0..128。两补采臂在同类型/算子读取完全相同的固定补采序列；全部普通目标按同潜在流配对、各臂只读取并支付自己的实际前缀。来源物理每life生成一次、每臂承担完整费用；B来源在模拟端预生成，规划状态仅到index30才接收。公共身份、已知改变行和对应关系可用，真核只在实际付费模拟抽样及最终评分端使用。

补采只更新持续原生A池，不改来源、A切换快照、B池或任何member；不创建目标、计划或证书。查询继续原A/type/family计数，48事件、阈值960；执行原source/pool/member事件阈值720/720/8640。查询.05与执行.05仍为每life/arm完整过程无条件上界.10，不能将选定端点或cohort声称为条件覆盖。预算、普通采样、补采及reset全部实计；完整来源、全部阶段历史和补采进入费用。相同固定补采数隔离的是预先获取时机，普通目标的适应性采样数量可以变化。

源码/协议在采样前留存。九个life×arm独立进程，各自冷查询、区间和归一化缓存；本轮并行方式不能用来宣称CPU效率提升。648条决定全部冻结后才事后读真核评分。记录来源和每批补采的身份、种子、游标、增量、时间位置，以及逐目标初始/逐批/终态计划、原生池、实际与预留账本。模型用process CPU并计入获取/池更新/初始化；观测、输出与总耗时用wall，记录所有controlled resets，不重复加总子计时。

沿用V245的11项资格形状：BEFORE晚B查询≥27/36、返场≥54/72；分别对DEFERRED和REBUILD要求晚B查询、返场查询、全周期联合完成数不下降；含来源与补采的总观测费用≤DEFERRED且严格<REBUILD；全部留存计划及实际执行的查询/执行/不可达证书、目标上界错误、风险违例均0。额外报告首个/后续同类型返场查询、全部阶段质量、普通采样分配、补采成本和模型CPU。独立审计需valid=true，复算来源/目标/补采流、时序、原生池、全部证明、停止及费用，不调用新producer或优化器。失败不追加种子/配额或修改Gate。
