# V134：局部扩容有增益，全局条件未显示额外收益

已实现并完成全局拥挤条件（GLOBAL）与局部扩容（CAPACITY）的对照。两者从同一来源权重初始化，分配相同参数量，每次使用32个特征，保持原单步TD、学习率及新增转移预算。每种方法覆盖四条来源历史、两个查询，每个组合训练524,288条转移；最终检查点为主比较，每历史每查询外评16局。

| 最终平均效用 | risk1 | risk8 |
|---|---:|---:|
| 冻结父策略 | 5.205 | −0.545 |
| 原单步 SINGLE | 6.061 | −0.315 |
| 全局条件 GLOBAL | 5.873 | 1.302 |
| 局部扩容 CAPACITY | 6.242 | 1.664 |
| **GLOBAL−SINGLE** | **−0.187** | **+1.617** |
| **GLOBAL−CAPACITY** | **−0.369** | **−0.362** |

**不采用GLOBAL作为主方法，结束当前全局条件位的改动路线。** GLOBAL相对SINGLE改善的历史数为2/4、3/4；相对CAPACITY为1/4、3/4，但两查询平均效用均较低。risk8的平均劣势来自一条历史的较大下降，另外三条历史改善。

CAPACITY相对父策略提高1.037／2.209，两个查询均4/4历史改善；相对SINGLE提高0.182／1.979，分别2/4、3/4改善。这支持保留局部扩容作为后续对照，尚不支持全局条件具有独立优势。原单步risk8仍从中期1.625回落到最终−0.315，3/4历史下降；完整曲线全部保留。

同一叶端价值下的直接决策与H2规划对照已在[V135](FROZEN_LEAF_PLANNING_V135_RESULTS.md)完成：四项比较均4/4历史改善，同时每步价值预测增加约44倍。下一步固定H2策略，学习可按新查询重组的后果知识。

完成与成本：26项定向测试、30项独立检查通过，complete与primary_complete均为true。训练12,582,912条转移、12,581,223次更新，留存24个最终ACTIVE前缀和24个pending项，无cutoff。外评1,280个物理游戏全部终态（133胜），形成2,048条逻辑记录；本轮共13,635,650条真实转移，模型生成采样0，历史来源成本另列。三个零点模型各在98,792次决策、355,294个合法动作值上精确匹配父策略。主运行一次1457.66秒、分析一次66.64秒，stderr均为空。

局限：只有四条来源历史及一种全局条件、一个局部扩容对照，训练访问分布也随策略改变。两种条件化模型各14,172,488个参数，是SINGLE的两倍；实际更新特征平方范数均值为33.571／33.245，不能称有效更新步长完全匹配。GLOBAL拥挤参数组承担19.36%的更新特征，CAPACITY占用参数组为64.70%；训练新增条件格读取分别3.08亿／6.17亿次。当前仍是两个查询分别训练的标量价值，尚未解决通用后果复用、稳定保留或一般战略学习。U005保持FAIL，U006未启动。
