# V235：必要行投影混合的有效性证明

本证明不评估任何留存证书。统计假设与V230/V231一致：每个固定真实类型及机制范围有固定分类行核；已选择算子的下一次随机结果条件于本臂目标历史与已获取共享来源仍服从该行核。类型、B→A对应和变化行来自本阶段已声明的已知类型接口。算子及批次数量在本批结果揭示前确定。

## 单条事件与真实时间线

固定life、arm、A/B范围、类型和必要行投影集合F。沿真实获取顺序，删除另一臂的全部目标揭示，得到本臂获取时钟。过滤族仅包含本臂此前目标结果、已获取共享来源和已声明的固定接口，不包含另一臂的目标结果、采样长度或停止消息。每次本臂时钟上的揭示，对F内且属于该事件的观测更新投影计数，其余观测乘子为1。投影只合并动作差真正同值的结果；选择算子可以读取本臂此前完整类别，不需要仅依赖投影。

V231两臂在同一life/index/operator使用相同目标seed，所以目标结果相关，另一臂甚至可能已揭示本臂即将读取的结果。不能相对于包含两臂结果的过滤族声称下一结果仍为随机行核。冻结runner的run_target只接收states[arm]、本臂member和本臂work；BALANCED及GAP选择器只读这些输入产生的plan。各臂state独立初始化，区间cache也按臂切换；共享来源的生成不读取任何目标结果。因此本臂获取对上述本臂过滤族可预测。跨臂相关不影响各自的Ville保证，必要时union bound也不要求独立。

每个投影行r的K_r类别采用Dirichlet(1/2,…,1/2)先验。对已计入计数k_r，n_r=Σ_c k_rc：

    m_r(k_r) = Γ(K_r/2)/Γ(n_r+K_r/2)
               × Π_c Γ(k_rc+1/2)/Γ(1/2)
    L_t(q) = Π_r Π_c q_rc^k_rc
    M_t = Π_r m_r(k_r)
    E_t(q) = M_t/L_t(q), 0^0=1.

若下一次计入结果在r行的类别c，真实投影参数为q，则E更新因子为

    (k_rc+1/2)/[(n_r+K_r/2) q_rc].

在内点q的条件期望为1；边界时仅对q_rc>0求和，期望≤1。故E_t(q_true)是相对于本臂过滤族、从1开始的非负supermartingale。这里行积是本臂实际获取路径上的联合过程，不能理解为任意二维/三维前缀网格均有效，也不声明包含两臂目标历史的全局martingale。行独立先验使混合可以写成行积；事件之间无需独立。

冻结V231 runner的实际获取顺序为：A来源→24个A目标→B来源→24个B目标→24个A_RETURN目标。B来源不是在A目标前获取。物理来源样本在两臂之间共享，每臂事件计入一次；另一臂的目标观测被本臂事件忽略。

* A事件计入其类型的A来源、A目标和A_RETURN目标，忽略所有B范围结果。
* B事件从时间零预先定义。变化行只计入B来源及B目标。未变行计入对应A来源、A→B切换前的A目标、B来源及B目标，忽略A_RETURN。B→A对应和变化行预先固定，因此所有计入选择均可预测。被继承A观测的行核等于B真实行核。

终态计数与V233 tapes完全一致。Dirichlet混合及分类likelihood仅依赖计数，所以队列中的表示顺序不改变终态E；此性质不替代上述物理时间线证明。不将旧A和B置信事件相乘，也不把已经计入的来源再次计入。

## 八个事件族与预算

S表示SHORT_DELIVERY二分类；D_DEL表示DETOUR_DELIVERY对其余结果；D_REC表示DETOUR_RECOVERY对其余结果；Dfull保留DETOUR三分类；R表示RETRY_DELIVERY二分类。

| 无序动作对 | goal必要投影 | risk必要投影 |
|---|---|---|
| WAIT / SHORT | S | S |
| WAIT / RETURN | D_DEL | Dfull |
| WAIT / RETRY | Dfull+R | Dfull+R |
| SHORT / RETURN | S+D_DEL | S+Dfull |
| SHORT / RETRY | S+Dfull+R | S+Dfull+R |
| RETURN / RETRY | D_REC+R | D_REC+R |

去重为8族。每life、arm固定8×2范围×3类型=48条事件。T=960、δ=1/20时，由Ville及union bound：

    P(存在任一48事件、任一本臂获取前缀 E_t(q_true)>960) ≤48/960=.05.

方向、两查询和已知operating/retry费用只改变同一个投影参数空间内的动作差坏原假设，复用真实参数事件，不另分δ。reward选择WAIT的确定获证不使用随机事件。该.05是每life、arm的保证，不是六个life/arm组合的实验整体.05。

## 联合坏原假设证书

固定某个比较的精确投影动作差g(q)=U(alternative)−U(chosen)，坏原假设H={q:g(q)≥1/20}。在上述共同真实参数覆盖事件上，如果真实核在H，任意有效的上界

    U ≥ sup_{q∈H} L_t(q)

满足M_t/U≤M_t/L_t(q_true)≤960。因此仅当M的向下界除以U的向上界严格大于960，才可以排除整个H。精确证明H为空也可获证。适应性选择比较、终态、已知费用和所选策略不破坏保证，因为共同事件已同时覆盖所需真实投影参数及本臂实际路径上的全部获取前缀。profile比本身不必是一个martingale；它在每个真实坏参数下被有效E过程支配。数值优化器只可建议有效全域上界，不能用局部最优替代sup。

## 与V232的关系及边界

V232使用原始分类投影：A全核及A预声明未变两行阈值480，B全核阈值240，另有member事件。V235的S+Dfull+R与V232同一全核投影及先验；若算子掩码和计数都相同，阈值960使这条单独区域更宽，不是增强。V235的Dfull+R在变化行为S时、S+Dfull在变化行为R时，也与原A未变两行使用相同混合公式。这只是公式层面的关系；不同数据计数不能据此作区域包含判断。

独立前缀结构审计在12个待检留存反例涉及的必要终态投影中，未发现与V232实际应用的某个已保存前缀同时具有相同算子掩码和计数的情况：B的必要终态计数合并了未变A行，而旧B全核前缀仅含B计数；A的必要终态投影删除了无关行，而旧A全核仍包含R。故这些留存比较不能仅凭公式重合判作等价区域。这里没有计算likelihood比，也没有声称新区域一定更强。不能声称八族全部新颖或全部强于V232。

D_DEL/D_REC采用Beta(1/2,1/2)是明确的新投影先验：对旧Dirichlet(1/2,1/2,1/2)合并两类，诱导先验实际为Beta(1/2,1)，并非新的Jeffreys Bernoulli先验。因此投影区域不存在自动包含关系。移除无关行及改变投影可提高特定比较的证据，但是否排除留存反例须随后按冻结方案单独检验。若全部相关反例仍可行，不应实现等价的证书优化器。

已知类型及机制对应、固定行核与可预测获取是必要前提。本证明不建立未知类型归属、模型错误、任意Cartesian前缀组合或新付费生命周期上的有效性，也不修改旧科学Gate。

## 条件完整资格：投影分母嵌入与32格上界

本节不计算留存数据。对于D_DEL投影，将二分类计数(k,n−k)嵌入原三类为(DELIVERY=k,RECOVERY=0,LOST=n−k)。对于D_REC投影，嵌入为(DELIVERY=0,RECOVERY=k,LOST=n−k)。未用行全部计数为0。分子继续使用实际二分类Jeffreys混合，不能使用这些人工嵌入计数的三分类混合。

在任意原三类参数p下，D_DEL嵌入likelihood为p_DEL^k p_LOST^(n−k)，不超过投影likelihood p_DEL^k(1−p_DEL)^(n−k)。反向构造p_REC=0、p_LOST=1−p_DEL便取得相等。D_REC同理：p_REC^k p_LOST^(n−k)不超过p_REC^k(1−p_REC)^(n−k)，令p_DEL=0可取得相等。其余必要行原样保留，未用行likelihood恒为1。因此，只要动作差在被合并的两个类别上同值，原simplex嵌入的坏假设最大likelihood恰等于投影坏假设最大likelihood。零计数类别是概率嵌入的自由坐标，不是额外观测。

所有冻结族均满足同值要求。D_DEL只用于goal的WAIT↔RETURN和SHORT↔RETURN，DETOUR_RECOVERY及LOST均没有goal交付收益。D_REC只用于RETURN↔RETRY：两动作的共同D前缀及费用抵消，差值仅为±p_REC(4q_R−retry_cost)或±p_REC(8q_R−4−retry_cost)，因此DELIVERY及LOST的差值系数均为0。反转方向只使系数取负，已知operating费用是常数，retry费用只修改p_REC系数，均保留同值关系。其余族不合并D三类；遗漏的算子本来就不出现在对应动作差中。

含RETRY的动作差可写为c+a_S·p_S+a_D·p_D+b p_REC q_R；b为0或固定符号的±4、±8。p_REC≥0，所以每个R区间内，以右端点(b≥0)或左端点(b<0)代入q_R，给出对全部S/D参数统一成立的动作差上界。故该区间原坏假设包含于端点放宽的线性坏假设。将R行likelihood在区间内的最大值与此放宽S/D坏假设的最大likelihood相乘，仍是原坏likelihood上界。

固定32个闭区间[j/32,(j+1)/32]覆盖[0,1]，取全部非空叶的上界最大值即可覆盖整个非线性坏假设。b=0时一格[0,1]足够。原V232 _leaf的λ≥0拉格朗日放宽和合法ν的simplex弱对偶，连同向外数值重算，适用于上述嵌入计数；优化器只建议λ/ν，不提供有效性本身。分区端点放宽可能使证书保守，但不会产生错误获证。
