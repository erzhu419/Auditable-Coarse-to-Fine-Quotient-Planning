# V139：局部组合跨过了整段复用瓶颈

将整盘联合索引拆成共享的四格行程序与动态生成补丁，保留两步完整出口、奖励、终态和原 H2 读出。四条历史均使用 V138 原有训练窗口，整段程序与具体缓存按相同前缀直接引用。

**本轮组合适用性结果为正。** 新的 64 局产生 2,031 个未见完整数值绑定：

|---|---:|---:|---:|

| 8 | 2,031/2,031（100%） | 0 | 0 |
| 64 | 2,031/2,031（100%） | 1/2,031 | 0 |

第 1 局覆盖率按游戏→历史等权为 85.51%，第 8/64 局均为 100%。全部命中的出口、奖励与终态正确，5,805 次 H2 续算的全部合法动作值和选择精确一致。每条历史第 8 局已达到 34 条局部程序，到第 64 局不再增长；四库共 136 条、24,925 字节，对照整段程序 8,023 条、7,547,395 字节，具体缓存 8,029 条、1,803,284 字节。

成本已计入局部匹配、组装、出生补丁、终态分类、观察验证、编译和续算。第 64 局快照完成全部组合查询累计 0.390 秒；整段查询累计 0.022 秒，但仅返回一个出口，不能据此作等输出速度比较。25 项有限测试、39 项独立检查通过；主运行一次 9.15 秒、分析一次 4.05 秒，stderr 均为 0。新增训练采样为 0，评估新增 63,944 条真实转移、3,097,972 个枚举模型后继，随机模型采样为 0。

下一步结束局部缓存优化，转向从经历中形成带条件分支和退出条件的短策略程序。在同等总模型展开预算下，与原 H2、同长度同数量的随机程序比较整局效用，并检验旧查询能力；生成、筛选和回退成本全部计入。核心检验是程序的选择与组织是否产生决策收益。

局限：组合语法与守卫编译依赖已识别动力学，动作和生成描述由输入给定；本轮验证了这些条件出口的复用，没有发现新物理规律。64 局全部由原 H2 控制（30 胜、34 负），没有策略收益比较，尚未解决一般战略学习。U005 仍为 FAIL，U006 未启动。
