64 条目标训练序列和全部评价流均为新数据。每阶段先支付 SOURCE 自然整局检测
观测；路由只看当前检测统计。实际创建新库时，从原 SOURCE 初始化两个学习臂，
共同使用 131,072 raw 的新 SOURCE 采集队列、前 80% 完整游戏训练，再冻结参数。
复用旧库时不补全训练队列、不重新拟合。实际返回路由进入最终 A 指标。

60 项新增有限测试通过；唯一完整独立核验重建 **266,895** 条新采集记录，核对
物理游戏、检测与路由、训练标签和预算、收益与留存。执行及核验均 exit 0、stderr 0。
**30,720** 局新评价全部自然终止，各臂 10,240 局；SOURCE / MC / LOCAL 分别胜
4,258 / 4,276 / 5,245 局。原 U005 仍 FAIL，U006 未启动。

实际路径为 62/64 条 `0→1→0`，另两条为 `0→1→2`。life 61、63 的返回 A
检测对旧 A 的 log BF 为 −0.181864、−0.566161，对 B 为 −95.015459、−154.480376。
现有零阈值规则立即创建并使用新库，旧 A 参数仍完整保留。两个新 A 库分别使
LOCAL 相对首次 A 改变 **+0.937622、−0.657471**；其余 62 条精确不变。
因此剩余瓶颈是检测不确定时误建并切换新库，而非旧参数被覆盖。

实际创建 **130** 个库，包含两次额外采集；支付新训练 raw **17,173,154**，其中
检测 133,794、主采集 17,039,360；56,827 个未完整尾部 raw 已付且不参与标签训练。
计入原 SOURCE 和动力学后，各臂经济训练输入为 **28,452,746** raw；两个学习臂

本轮 worker / compiler / coordinator CPU 为 1,779.59 / 15.70 / 35.71 秒，
wall 509.71 秒；包含的采集、重建、拟合、评价分量不重复相加。

## 局限与下一阶段

区间以四个固定 SOURCE 父模型为条件，尚无新来源训练确认；A/B 总体收益不代表
每个来源上的每项任务均获益。采集仍由共同 SOURCE 策略承载，阶段边界由实验提供，
评价使用完整 H2；一般战略持续学习与同环境持续提升未建立。LOCAL 的容量、写入量
为 MC 两倍，评价 CPU 高约 36%，没有计算效率优势结论。旧 SOURCE 秒数是继承的
历史耗时，全历史 CPU 尚未实测闭合。独立核验未重新拟合参数、执行评价动作或重抽 CI。

下一阶段将“候选新颖性”与“创建并激活新库”分开：证据模糊时按需取得新的独立
观测，再决定复用或新建。事前冻结确认规则和采样上限，用新的更长任务序列同时检验
真正新情境的识别、返回情境的复用、完整收益和追加观测成本。V308 仅定位问题，
不用于选择 BF 阈值或放宽留存标准；随后推进容量匹配的贡献对照与新来源确认。
