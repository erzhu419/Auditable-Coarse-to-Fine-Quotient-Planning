# V236冻结：来源训练的预测证据

本轮只复用V235已独立审计的原24个终态与付费tapes；策略、任务费用、观测数量和旧Gate不变。已查看的V235结果只用于确定本轮唯一研究问题，不选择先验、分割点或阈值。所有中途文件保存在本项目reports目录。

训练/验证划分依据原provenance的kind/context/operator/queue_start/queue_end，固定如下：A及A_RETURN终态的各行仅以A source训练，所有后续A/A_RETURN target验证。B变化算子仅以B source训练、B target验证；B未变化算子以A source训练，随后继承的A target、B source和B target均用于验证。B不包括A_RETURN。使用已知类型和对应关系，源类别投影与V235八族完全一致。训练观测不能再次进入验证分母，每条留存观测必须恰好属于训练或验证。

每行训练计数s、验证计数t，固定先验Dirichlet(1/2,…,1/2)，预测分子Q=M(s+t)/M(s)，验证likelihood仅L(t)。各行可有不同训练时刻；在各臂自己的实际获取过滤族上逐行启动，再乘为一个过程。其他臂目标结果不进入本臂过滤族；共享来源在每个本臂过程内只出现一次。不得用“条件于全部训练块”的论证掩盖B中交错的训练/验证。来源块用于训练预测器，其全部原获取费用仍计入。

48个预声明事件（八族×A/B×三类型）、δ=.05、阈值960保持不变。动作方向、goal/risk查询与已知费用共享同一真参数事件。新旧证书不能事后OR组合，不更改旧证书或旧科学Gate。

先运行一次固定9反例诊断：V235后置诊断接受的6个SHORT↔RETURN risk反例，以及V234的3个RETURN↔RETRY终态矩形反例。每个仅检验原chosen/alternative/query的必要投影区域，精确比较Q≤960L(t)，动作差须仍严格超过.05。不搜索新反例、不扫其他投影、训练块、先验或预算。记录完整训练/验证计数、原费用、联合与条件预测证据的代数关系，以及验证MLE到反例的似然损失和预测分子的代价；这些是观测几何，不是新增样本量保证。

只有6个主要风险反例全部被新区域排除，且独立审计通过，才执行完整24例资格验证；否则本轮停止，报告仍被接受的反例。不接受固定反例仅满足推进必要条件，不能宣称获证或数据充分。

条件完整资格：原V232合法对偶/向外80位界和固定32格不变，分母全域坏假设gap≥.05使用验证计数，分子使用真实必要投影的精确Q。若Q向下界减全域坏likelihood向上界严格超过log960向上界，或坏假设精确为空，才认证该比较。每查询AND三个替代动作，再AND三查询；reward WAIT解析认证。缓存同时包含训练和验证投影计数、费用、查询、方向与分区。所有证书留存后才读取原策略已保存的真regret评分。

采用必要条件仍为保留全部12个原正对照且改善原12个失败。独立审计不导入本轮生产代码：从原tapes重划训练/验证，用训练计数初始化的Dirichlet逐次预测递推复核Q，精确验证成员关系和动作差；完整资格另核对验证分母、投影嵌入、全域对偶与32格覆盖。诊断与条件资格各最多正式运行一次，无新增环境获取。该协议只检验已知类型下的来源预测证据，不证明一般战略学习成功。
