# V236：来源训练的预测证据

本证明沿用V230/V231的固定行核、已知真实类型、B→A对应及变化行接口；不读取留存反例的统计值。训练范围与预测规则须在本轮评估前冻结。

## 留存接口与训练时间

冻结V231获取顺序为A来源→24个A目标→B来源→24个B目标→24个A_RETURN目标。来源每类型每行在A获取384次、在B获取128次。冻结V233/V234 tapes的每行`provenance`保留`kind`、`context`、`index`、`availability_order`和`queue_start/queue_end`，足以直接切分既有队列，不需要调用真实行核或重放随机数。

| 事件行 | 唯一训练块 | 后续验证观测 |
|---|---|---|
| A行 | 本类型A来源 | 本臂A目标及A_RETURN目标 |
| B变化行 | 本类型B来源 | 本臂B目标 |
| B未变行 | 对应类型A来源 | 本臂切换前A目标、B来源、本臂B目标 |

B未变行的B来源是验证，不能再次训练；其行核按固定接口与对应A行相同。B事件不计A_RETURN。来源训练只在对应行第一次验证之前完成，不用目标观测重选训练块。

B事件的不同必要行可能在不同时间完成训练：未变行已经验证A目标时，变化行的B来源尚未获取。因此有效性依赖下述按行启动的真实时间过程，不能将所有训练块视为统一在所有验证之前发生。

## 精确预测likelihood与联合过程

固定必要投影行r，类别数为K，训练计数为a，累计验证计数为k。使用固定Jeffreys先验及训练后验Dirichlet(a_1+1/2,…,a_K+1/2)。令

    m_r(x) = Γ(K/2)/Γ(|x|+K/2) × Π_c Γ(x_c+1/2)/Γ(1/2)
    Q_r(k | a) = m_r(a+k)/m_r(a)
    L_r(k;q) = Π_c q_c^k_c
    E_t(q) = Π_r Q_r(k_r | a_r)/L_r(k_r;q_r).

每行在其来源训练结束后才启动；此前以及不属该事件的观测乘子为1。该行下一次验证类别c的更新因子为

    (a_c+k_c+1/2) / [(|a|+|k|+K/2) q_c].

预测分布在结果揭示前可测且总和为1。在真实内点q下，条件期望为1；边界q下只对正概率类别求和，条件期望不超过1。故行启动及更新可交错，联合E仍是从1开始的非负supermartingale。变化行B训练的观测被该行事件忽略，但未变行的B来源按其训练后预测分布更新验证过程。训练计数不进入L；将来源同时放入后验和验证分母将改变本方案。

过滤族只包含本臂此前目标结果、已获取的公共来源和固定已知接口。冻结V231两臂共享同一life/index/operator的目标seed，另一臂结果必须排除。冻结runner的本臂state、cache及选择器只读取本臂历史；来源生成不读取目标结果。由此获取选择可预测。跨臂相关不影响各自Ville不等式或union bound。这里不声称包含另一臂目标结果的全局martingale，也不声称任意Cartesian行前缀组合有效。

八个必要投影族及每life、arm的48事件预算与V235一致：S、D_DEL、D_FULL、D_FULL_R、S_D_DEL、S_D_FULL、S_D_FULL_R、D_REC_R。类别投影先于训练计数；D_DEL和D_REC各自使用二分类Jeffreys先验，不将三分类后验边缘化成不同先验。各事件共同阈值960，故真实投影核沿本臂全部实际获取前缀同时满足E≤960的概率至少1−48/960=.95。方向、查询及已知费用复用同一真实参数事件。该概率按每life、arm计，不是六个life/arm组合的整体保证。

## 全域查询证书

对精确动作差g(q)=U(alternative)−U(chosen)，坏原假设H={q:g(q)≥1/20}。令Q为训练后预测likelihood，L仅使用验证计数。若有效全域上界U≥sup_{q∈H}L(q)，则Q/U>960能够排除H：任何真实坏参数都会违反相应共同覆盖事件。查询或动作根据既有历史选择，不改变这个共同事件。

V235必要行嵌入与固定32个R区间的外向上界可以复用，但输入必须是验证计数，分子必须改为Q。数值优化器只建议全域上界的合法弱对偶参数。固定训练后验下Q是验证likelihood的后验平均，因此Q≤max_q L(q)；若验证MLE本身属于H，不能获证。两个事实都与训练计数的数值大小无关。

## 费用与适用范围

每life每臂引用的累计物理来源费用仍为A阶段3456、B及A_RETURN阶段4608；每life实际公共来源获取4608次，两臂共用而非重复获取。训练/验证切分不消除来源、历史目标或当前目标费用。tape中`fees.total_reference_paid_samples`保持原值，各终态累计引用费用不能相加当作新的物理获取总量。
