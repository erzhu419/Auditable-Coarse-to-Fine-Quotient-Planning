# V66：直接构造可递推的因果遗忘商

2026-09-12，在运行旧开发根上的新方法前冻结。用户要求优先处理战略抽象主线；停止扩展 V65 后提出的查询缓存计划。本轮保持标准 4×4 2048，不训练旧 classifier、规则树或 LMTA 网络。

## 表示与充分条件

每根仅读取初始棋盘和有限 horizon，自动判定哪些砖块不可能参与后续合并。对每个当前只出现一次的 rank r，去掉它自身，使用无消耗、同步的数量上界：

`U[t+1,k] = U[t,k] + floor(U[t,k-1]/2) + 1[k in {1,2}]`。

运行 H+1 次；若 rank r 的伙伴上界仍为零，就将它编码为匿名占位符 -1。重复 rank 保留；已获胜的输入先终止。遗忘集合在该根整个构建期间固定，不使用后继真值挑选规则。匿名占位符可以移动、阻挡和占用空间，永远不能互相合并。保留的数值砖块按正常规则合并；随机生成分布保持。

这个上界不消耗已有砖块，同时加入两种可能生成，故逐层支配真实计数。被遗忘的砖块无法找到伙伴；额外时域覆盖最终 LOST 判定需要的合法动作检查。删除其数值不改变合并、奖励、空位或合法动作。由一步分布对应关系及有限时域归纳，同一抽象策略的收益、失败和成功概率可以在抽象模型内递推。这是已知机制下的保守结构合成，非未知动力学学习。

## 一次固定对照

- 使用 `cases_v7()` 的全部 16 个已暴露根，保留原 H2/H3；不挑选有压缩的棋盘，不称独立确认集。
- BASELINE 保留全部 rank；CAUSAL 使用上述充分条件；UNSAFE 遗忘所有单例 rank，故可能错误删除未来可合并变量，作为机制破坏对照。三臂共用同一个符号 swipe/spawn 实现，避免把换模拟器的速度计作抽象收益。
- 三臂均从根直接展开各自模型，相同终态折叠。CAUSAL 不读取具体后继闭包，也不以 ground 搜索编码状态；只有独立审计可以构造 ground 模型。每例轮转三臂顺序。
- 构建一次后分别规划旧十查询和四个新数值查询：`(reward,risk,goal)` 为 `(1,.004,.3)`、`(1,.02,.3)`、`(.4,.4,1.2)`、`(1,.3,.2)`。规则与动力学不使用这些查询或答案。
- 每个模型及独立真实闭包上限为 30,000 状态；不截断后继，不替换根，不扩大上限续跑。保留异常和已付费工作。整个主实验只运行一次。

## 决定是否解决本轮结构问题的证据

三臂模型和政策冻结后，用独立标准 2048 完整闭包逐状态／动作核对终态、合法动作、奖励与抽象后继联合概率（数值容差 1e-12）。独立 ground DP 只算一次，复用于三臂审计；核对全部查询的完整提升策略、收益／失败／成功预测误差及最优值损失，报告严格查询切换和动作平手差异。UNSAFE 的不一致是对照结果，不能混为 CAUSAL 实现失败。

记录每根和总体活跃状态、动作行、生成分支、规划展开和包含编码信息的模型字节。终态折叠不算战略压缩。构建、规则合成、14 查询、序列化、准备与清理全部计入变体成本；独立闭包、参考商、审计、进程验证和开发费用另列并保留。只减少算术时间不能算压缩成立。

每个 CAUSAL 模型单独落盘，在新进程中只加载符号动力学重新完成 14 查询；核对全部政策与值，并检查无 ground domain 导入。模型文件不携带具体棋盘状态映射。记录可复用编码／模型存储，不能把缓存政策当作这项验证。

只有 CAUSAL 在全部声明根保持受控后果，并实际减少活跃状态及规划展开，才支持本轮结构桥接。压缩程度和全费用收益分别报告，不能用某一项通过代替整体目标。若保守条件没有形成实际压缩，应直接定位剩余可合并区别，不以更多计时或采样续调掩盖失败。
