# V14：排除不可能的目标奖励，完整策略与成本共同改善

V14 已完成全部 16 个原始根、48 个实例／种子组合和每方法 480 个查询场景。32 项针对性测试通过；唯一一轮运行耗时 46.515 秒，结果序列化另为 11.405 秒，stderr 为 0 字节，原始 JSON 为 67,262,870 字节。四个补采方案的全部路径均满足包含初始观测的 128 行上限。

**质量守恒上界的预期作用在本轮得到支持。** 原上界重新执行后，与 V13 的 96 个前缀及 960 棵执行树精确一致。新上界在质量不足根的 60 组 goal／no-goal 查询配对中，全部获取、动作、区间历史和真实后果一致；原上界只有 12/60 组一致。

执行时补采的完整根策略最优数由原上界的 435/480 提高到 **453/480**，18 项价值改善、零退化。原来的五项 ONLINE 相对 UPFRONT 退化全部恢复为真实最优。新方法平均取 30.617 行，单查询独立成本 31.125 ms；同期原方法为 32.725 行、34.358 ms。完整经验基线同为 453/480 最优，但新方法仍有 8 项完整根价值略低，最大新增损失为 0.000810547。

## 固定方法与信息范围

[执行前协议](../specs/CONTROLLED_PREDICTIVE_MASS_BOUND_V14.md)和[名册](controlled_predictive_cohort_roster_v14.json)保留原全部根、horizon、三个种子及十查询。两种上界均使用 V13 增量更新，采样流、每行 256 个样本、前沿与动作平局、128 行总预算、执行时跨步额度和经验停止容差保持不变。来源拟合／调用／费用为零。

唯一数学变化是：对 ACTIVE 状态的未观测动作，若现有棋盘质量 `m + 4*h < 2048`，则把上界中的目标奖励项置零。合并保持质量，每步新方块最多增加 4，所以此条件排除了任意剩余历史中的 2,048 目标。等号保留原界，已 WON 的终态奖励保持不变；其他奖励和失败边界公式、已观测转移的递推保持不变。计算只使用当前棋盘的既有 profile，无须访问未观测随机支持。

LEGACY 与 MASS_BOUND 各自从根建立十查询的 32／128 行嵌套前缀，分别使用自己的 32 行快照进行 UPFRONT／ONLINE；128 行后缀仅属于 Stage A，不向执行预热。另保留两个各自的 frozen32，以及共享付费全行样本的完整状态模型和零容差精确经验商，共八个方法。旧 V13 仅在本轮全部策略冻结后读取用于复现核对，本轮 LEGACY 数据重新获取并实际计费。

历史评价继续按当前动作选定后才揭示其真实后继，兄弟分支的模型与预算相互独立。精确最优标签只用于冻结后的评价，保留完整根策略后果和实际路径成本。

## 局限与下一步

全部输入是已暴露开发材料，原 split 只是历史标签，480 项相关查询不代表独立样本。此轮没有来源表示迁移或新的正式科学 Gate。质量条件是保守充分条件，未排除目标不代表目标可达；经验区间仍不是实际概率的统计置信区间。新旧上界从初始构建开始生效，数据量可能不同；补采组匹配总上限，全行基线使用更大的观测预算。计时来自一次串行本地运行，路径加权操作成本不是实测线上端到端延迟，也不使用 V13 的旧墙钟作加速对照。历史产物只复现固定行流中的声明历史，没有任意新历史或新查询的重规划能力。

后续部分观测开发保留 **V14 质量上界＋增量更新＋ONLINE** 作为候选。均匀采样＋零容差精确经验商仍为完整有限规划基线，需要可执行规则时仍保留 V9 从头构建。来源优先级继续暂停。

下一步应固定当前结构上界，单独检验**已观测动作的采样不确定性与重复采样**。预算按实际抽样次数计算，重复获取同一动作也收费；保留不重采的 V14 对照，并把当前旧反例作为回归材料。重点是到达决策中的动作差异和完整策略后果，不能仅以经验区间闭合或根首动作正确为停止证据。下一阶段须先冻结采样分配、停止规则、完整成本与验证名册，本轮没有追加这些运行或改阈值。
