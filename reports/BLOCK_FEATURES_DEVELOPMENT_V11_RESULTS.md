# V11：固定特征块与活跃状态中间结果的同期比较

**V11 保持全部已比较语义，但本轮仍未观察到平均构建成本收益。** 与同期 V9 相比，主场景从头构建慢 2.08%、来源适配慢 12.65%；整族留出目标分别慢 6.52%、20.11%。终态特征上下文已消除，混合组也不再通过逐标量访问补齐向量，但实际滑动、目标签名检查与聚合工作没有减少。

当前继续使用 V9 从头目标方法构建可执行规则，以均匀采样＋零容差精确经验商作为有限规划基线。V10/V11 保留为实现成本的负面比较；后续优先检验目标观测与构建规模，不再以特征访问调度为主线。

八组为完整状态、精确经验商、原冻结来源规则、V9 从头目标、V9 来源适配、V11 从头目标、V11 来源适配，以及 V11 适配后动作后果打乱控制。前七组轮转构建，控制最后构建。同期 V9/V11 分别核对规则、有限模型、编码对照和十查询策略的精确相等性，比较开销单列。

V11 使用固定五个特征块：原棋盘七特征、四个动作各六特征。来源路径读取某个特征时计算其所属块；目标混合签名组通过一次批量入口补齐其余块，避免逐标量物化。各状态的块保存在固定列表中，不建立标量字典或跨状态棋盘缓存。

终态保留 V8 的判别与短路顺序，返回后不留特征上下文。ACTIVE 状态保存本状态的四个确定性滑动结果，供路径、混合组补齐和最终编码使用。相同棋盘在另一个状态中重新计算。原 31 特征值、分割顺序、编码编号、共享叶补丁、未访问编码、自底向上传播、未解决冲突与最终聚合均保持 V9。

与 [V10](LAZY_FEATURES_DEVELOPMENT_V10_RESULTS.md) 的历史工作计数比较，V11 去掉了每次混合组完整向量补齐中的 31 次标量分派。主场景从头／适配的标量索引请求从 V10 的 `109,191／85,185` 降到 `9,681／23,030`；留出目标从 `87,170／83,769` 降到 `7,004／11,508`。完整向量补齐次数分别为主场景 `3,210／2,005`、留出目标 `2,586／2,331`，没有补齐结果复用命中。

## 局限

所有根、机制族、查询均已暴露，种子与场景重复不是独立确认。目标仍需要完整有限闭包及全部动作行观测；本轮只比较计算实现，没有采样效率或冻结迁移的新证据。
