# V133：固定32步TD明显退化，不采用

已完成固定32步、终局锚定TD与原单步TD的比较。两者从相同来源模型初始化，各使用524,288条新增转移；4条历史各16局评估，最终检查点为主比较。

| 最终平均效用 | risk1 | risk8 |
|---|---:|---:|
| 冻结父策略 | 5.939 | −0.755 |
| 原单步TD | 6.570 | 0.563 |
| 32步TD | 2.368 | −6.664 |
| **32步−单步** | **−4.202** | **−7.226** |

**32步方案在两个查询的四条历史上全部退化，最终128局均未获胜，不采用。** 三个非零检查点也都劣于两项对照。单步相对父策略最终提高0.631／1.317，各3/4历史改善；但risk8从中期1.538回落到最终0.563，稳定性仍未解决。

全局局面条件化及等分配参数量的局部扩容对照已在[V134](CONTEXTUAL_NTUPLE_V134_RESULTS.md)完成：未显示全局条件的额外优势。下一步固定价值模型，比较直接决策与同一叶端价值下的有限模型规划，分离规划收益与计算成本。

完成与成本：30项测试首次通过，29项独立检查通过，complete与primary_complete均为true。训练8,388,608条转移、8,387,772次更新，留存16个最终ACTIVE前缀及264个未结算项，无cutoff。外评896个物理游戏全部终态；合计新增8,981,006条真实转移，模型生成采样0。两个零点模型各在104,208个决策及374,418个合法动作值上精确匹配父策略。主运行一次683.52秒、分析一次45.59秒，stderr均为空。

局限：本轮否定的是当前表示、更新规则与预算下的固定32步方案；延迟、目标方差和访问分布同时改变，不能外推到所有多步方法。后续V134未显示该全局条件的额外优势，仍未解决一般战略学习。U005保持FAIL，U006未启动。
