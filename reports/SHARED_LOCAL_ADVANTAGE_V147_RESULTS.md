已实现跨位置共享的局部表示：16 个按边界类别区分的单点特征、24 个无向邻接特征。保留原标签、OLD→NEW 训练顺序、32 轮、归一化 LMS 与动作门槛。SHARED 与旧 UPDATED 的训练尝试数同为 8,192；加入零权重 ZERO 对照后，四组共完成 256 局新游戏。

**不采用 SHARED，保留 H2。** H2 / ZERO / UPDATED / SHARED 各 64 局，分别赢 44 / 37 / 16 / 16 局。risk8 相对 UPDATED 的小幅均值改善仅来自一条历史，其余三条为负，不能视为稳定收益。

表示共享确实增强：NEW 留出特征的地址覆盖平方范数比例由 16.09% / 14.06% 升至 87.03% / 88.37%，训练空间投影由 1.78% / 1.47% 升至 37.52% / 37.71%；但效用 MSE 由 1.0889 / 20.5714 升至 1.2926 / 24.6250，OLD 留出误差也同时上升。原 173 个有效训练对中只有一个被共享表示合并为零，128 个 NEW 留出分歧均保持非零；简单的零差分退化不足以解释整体失败。SHARED 的 H1 采纳率为 21.1% / 22.0%，高于 ZERO 的 6.8% / 7.1%。

下一步固定 TRAIN 分歧起点、现有模型和 ZERO 预测，用预先固定的新后缀独立复测 H2 后续配对终局。检验原训练收益能否在独立标签上重现，再决定修改标签估计还是处理部署分布下的迁移失败；保留全部固定起点，不按旧标签正负挑选。

成本与验证：新增训练标签交互为 0，评估使用 239,979 次环境转移，全部游戏终止。SHARED 实际更新 5,504 次；特征秩读取 1,048,576 次，发出特征 655,360 次。23 项有限测试最终通过，测试修正记录保留；独立复核 58/58 通过，78 份冻结源码一致。主运行与独立分析各一次，63.96 / 81.41 秒，stderr 均为 0。分析另计 2,622,352 次重放 swipe、8,192 次 LMS oracle 尝试、16 次 SVD；既有交互成本按来源引用保留。

局限：本轮检验一个局部共享方案、四条学习历史，不作显著性声明。特征支持上升不是效用误差的因果分解；结果不能证明所有共享表示无效，也不能把标签噪声认作唯一原因。一般战略学习仍未解决，U005 FAIL、U006 未启动。
