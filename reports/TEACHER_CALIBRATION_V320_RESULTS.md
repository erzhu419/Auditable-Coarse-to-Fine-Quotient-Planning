# V320：查询状态上的教师奖励目标更低估

固定根/真实首次 spawn/已选 DIRECT 动作的终局校准已完成，独立核验 PASS。唯一主终点支持 QUERY 的联合教师目标相对 FACTUAL **更悲观**，不是学习收益：signed teacher error 差为 −0.433145，95% CI [−0.528076, −0.330458]；15/16 生命周期为负，四个父组均值都为负。

每个任务/轮次预先取 V319 原 16,384 组的 64 个等间距位置，两臂共用全部四个成员。先重放保存的 DIRECT，再由冻结 FIRST H2 续跑。真实回报包含该 DIRECT 及后续 score，不含进入 root 的动作奖励。此前提出的前缀在采样前改为等间距位置；前缀没有运行或择优比较。

## 范围与剩余问题

区间条件于固定 64 位置、既有 16 个 FIRST 生命周期、四个 SOURCE 和规定 DIRECT→FIRST H2 策略，以生命周期为单位父组内 bootstrap 20,000 次。FIRST_R 原先拟合 SOURCE 行为的回报，本轮实际续跑使用 FIRST H2；策略迁移、表示误差和共享参数干扰尚未拆开。本轮确认的是教师校准差异，不能单独证明该偏差造成 V319 的整局下降，也不能宣称算法已经改善或覆盖全部查询池。历史动力学与失败尝试 CPU 未知。U005 FAIL 保留，U006 未运行。
