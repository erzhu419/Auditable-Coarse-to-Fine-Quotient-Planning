# V237：固定终态后追加采样的必要预算

本诊断固定V236的三个ORACLE_GAP主要风险终态及其已接受反例，目标是比较75%的单个反例排除概率与原BALANCED/GAP全生命周期采样费用差。所有来源和原生命周期的其他付费采样保持原费用；只允许追加真正未观测、同一A类型行核的独立算子样本。不改变V236起始证据、阈值960或原科学Gate，不获取新样本。

## 条件错误概率与信息量

给定固定过去h，令q为该终态的固定坏核，e0=Q_h/L_h(q)。只需要S二分类、D三分类；无关行和其他类型在假想q世界中保持真实p的分布。新后缀的预测分布可以任意根据已知历史改变，只要下一结果的预测概率在揭示前可测且归一化。故在q下，未来E从e0开始为非负supermartingale。对任意本臂可预测采样和停止，条件Ville不等式给出

    P_q(未来任一时刻 E>960 | h) ≤ alpha = min(1,e0/960).

q虽来自已留存过去，但条件于h后是固定简单假设；这里只约束新后缀的条件分布。不得重用已经揭示的随机数结果，也不得让另一耦合臂的目标结果进入本臂后缀过滤族。

令E为在最多B次新算子样本内排除此固定反例的事件，beta=P_p(E|h)。真实p只用于诊断；学习器不获得p。对于相同的自适应获取规则，两世界下一次所选算子相同地由已揭示历史确定。停止后的空符号不含信息，转录KL的链式法则因此给出

    KL(P_p(transcript|h) || P_q(transcript|h))
      = Σ_a E_p[N_a|h] KL(p_a||q_a)
      ≤ E_p[N|h] Imax ≤ B Imax,
    Imax = max_a KL(p_a||q_a).

获取可以在所有支持的算子中自适应选择；无关行的KL为0。这个自适应转录改变测度不等式可参见[Kaufmann、Cappé和Garivier（2016），Lemma 1](https://www.jmlr.org/papers/volume17/kaufman16a/kaufman16a.pdf)。二元事件的数据处理不等式再给出KL(transcript)≥kl(beta,P_q(E|h))。当alpha<rho=3/4且beta≥rho时，二元KL对第一概率递增、对第二概率递减，从而

    E_p[N|h] ≥ kl(rho,alpha)/Imax.

这是达到所需排除概率的必要期望样本下界，且对任意上述获取策略成立。若Imax=0且alpha<rho，无法通过此后缀达到rho。若alpha≥rho，该论证没有正的必要下界。cap必须至少覆盖这个期望下界；批量16只能用于cap的向上整批换算，不能将期望值本身强行取整到16。

## 有限cap的排除概率上界

对于给定B，令beta_U为[alpha,1]上满足kl(beta_U,alpha)≤B Imax的最大值。如果B Imax≥log(1/alpha)，beta_U=1；否则唯一上支根给出beta_U。任何beta≤alpha本已低于此根，任何beta>alpha由上面的不等式受此根限制。因此P_p(E|h)≤beta_U，实际达到这个上界没有保证。

数值资格必须保守：必要期望样本下界采用kl(rho,alpha)的向下界除以Imax的向上界；判定75%不可达采用B·Imax向上界严格小于kl(rho,alpha)向下界。若报告根，须提供上支根的向上外界。优化器输出、均值类别续接或平均采样数不提供这个证明。

## 费用比较和结论范围

每life原两臂均引用4608次来源样本。原总费用之差仅来自实际目标获取；冻结三个life的GAP相对BALANCED剩余预算为2032、48、816次。分别把该life全部预算授予其一个固定GAP阻塞，是宽松的逐例必要条件；通过逐例条件不能证明多查询或整life共同可修复。

即使某life在全部额外预算下仍不能达到75%固定反例排除概率，也只排除：以V236固定终态及证据过程为起点、保留原生命周期其余费用、再追加新样本的修复方式。原终态之后已有其他付费目标；重排整生命周期获取、节省那些后续费用、延迟认证或改变统计构造均不属于本结论。该比较也不是REBUILD基线的成本或一般战略学习的不可能性。

固定反例排除仅是全域坏原假设认证的必要条件，75%是本次预算诊断的预先指定规划概率。它不等同于旧科学Gate，不证明查询获证概率、所有反例同时排除或新生命周期的实际成功率。
