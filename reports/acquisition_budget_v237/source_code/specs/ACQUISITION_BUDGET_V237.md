# V237冻结：关键反例排除的采样预算必要条件

本轮不优化来源先验、不生成虚拟观测或环境样本。固定V236的三个GAP主要SHORT↔RETURN risk反例：(life0,index58)、(life1,index56)、(life2,index55)。所选策略、反例参数、来源训练/验证计数、每life/arm的48事件与阈值960、任务费用和旧Gate全部保留。

成本核对发现V231只有GAP与BALANCED，两者都复用未变化知识，没有同接口同流的REBUILD留存对照。不能混用V229另一队列的重建节省。唯一匹配费用参照为V231总来源+目标费用：每life BALANCED/GAP分别14144/12112、17072/17024、17168/16352；差额2032、48、816，总2896。来源4608/life已计入。各终态累计费用不能相加；差额用尽时仅成本持平。

本轮预算问题限定为：在固定所选终态之后追加全新的同A行核验证采样，原生命周期其他费用保持留存值，能否在上述差额内，以至少3/4概率排除固定坏反例。3/4是阶段预算规划指标，沿用75%质量参照，但不是旧Gate的新定义。不重用已见的后续目标结果或随机数，不回填原终态证书，不假设追加采样会减少其余目标费用。

令e0为V236在该坏核q上的精确预测likelihood比，alpha=e0/960。本轮三例仍在区域内，故0<alpha≤1。未来每次获取的预测分布可任意可预测地变化并归一化，获取算子可自适应；沿本臂过滤族延续原过程。由条件Ville界，坏核q下未来越过960的概率不超过alpha。

只在全部留存输入和协议冻结之后，读取原V231任务的精确真行核p进行oracle必要条件诊断；真实概率不会进入任何学习、获取或证书决策。必要投影为S二分类、D完整三分类。非必要行在替代模型中取真核，KL为0；可假设最佳算法知道信息最多的行，取得有利的Imax=max_row KL(p_row||q_row)。

自适应采样的链式KL与二元数据处理给出：若未来硬上限为B条且排除概率为u，则kl(u,alpha)≤B Imax（u>alpha时）。要达到3/4，必要期望获取数至少kl(3/4,alpha)/Imax（alpha≥3/4时仅0下界）。每例报告各行KL、必要期望条数向下界、16条批次的必要硬上限、在整life差额B内的排除概率向上界。以KL分子向下界、Imax向上界形成必要条件；概率根固定64次有理二分，只保留可核验向上界。

同时汇总三个不同life的必要期望条数下界，与总2896差额对照，不将同life/arm的重复终态费用相加。不满足必要条件记预算不足；满足仅记未被下界排除，不能当作可行策略或查询获证。只排除一个固定反例是完整坏原假设认证的必要条件。

本轮唯一正式诊断及独立审计各一次。独立审计不导入V237生产代码，重建V236逐次预测e0、原任务真核和全部KL、数值方向与匹配费用。没有新科学Gate、置信区域、采样或证书。
